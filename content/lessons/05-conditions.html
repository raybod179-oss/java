شرط‌ها: if و switch

هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. if و else
  2. Truthy و Falsy
  3. عملگر سه‌تایی

  5. تمرین‌ها
۱

if و else

کد · قابل اجراjs
const score = 72;
if (score >= 90) {
  console.log("عالی");
} else if (score >= 60) {
  console.log("قبول");
} else {
  console.log("مردود");
}
۲

Truthy و Falsy

شرط فقط با true و false کار نمی‌کند. این مقدارها falsy هستند: false، 0، ""، null، undefined و NaN. بقیه truthy هستند.

کد · قابل اجراjs
const name = "";
if (name) console.log("نام دارد");
else console.log("نام خالی است");
console.log(Boolean("0"), Boolean([]));
۳

عملگر سه‌تایی

خلاصه‌ی if/else برای انتخاب یک مقدار.

کد · قابل اجراjs
const age = 16;
const label = age >= 18 ? "بزرگسال" : "نوجوان";
console.log(label);
۴

switch

وقتی یک مقدار را با چند حالت ثابت مقایسه می‌کنی.

کد · قابل اجراjs
const day = 3;
switch (day) {
  case 1: console.log("شنبه"); break;
  case 2: console.log("یکشنبه"); break;
  case 3: console.log("دوشنبه"); break;
  default: console.log("نامعتبر");
}
اشتباه رایج

اگر در switch بعد از هر case دستور break نگذاری، اجرا به case بعدی می‌ریزد.

★

تمرین‌ها

تمرین ۱

برنامه‌ای که دمای ۳۸ را «تب دارد» و کمتر را «سالم» چاپ کند

دیدن پاسخ
کد · قابل اجراjs
const t = 38;
console.log(t >= 38 ? "تب دارد" : "سالم");
تمرین ۲

با switch نام ماه را از شماره (۱ تا ۳) چاپ کن

دیدن پاسخ
کد · قابل اجراjs
const m = 2;
switch (m) {
  case 1: console.log("فروردین"); break;
  case 2: console.log("اردیبهشت"); break;
  case 3: console.log("خرداد"); break;
  default: console.log("؟");
}
روش تمرین

اول خودت حل کن، بعد پاسخ را ببین و با راه‌حل خودت مقایسه کن. چند راه درست برای یک مسئله وجود دارد.
