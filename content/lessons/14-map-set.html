Map، Set و متدهای Object

۱

Object.keys و values و entries

کد · قابل اجراjs
const stock = { apple: 5, banana: 0, pear: 12 };
console.log(Object.keys(stock));
console.log(Object.values(stock));
for (const [k, v] of Object.entries(stock)) console.log(k, v);
۲

Freeze و Seal

کد · قابل اجراjs
const cfg = Object.freeze({ mode: "prod" });
cfg.mode = "dev";             // بی‌صدا نادیده گرفته می‌شود
console.log(cfg.mode);
const o = Object.seal({ a: 1 });
o.a = 2;                       // تغییر مقدار مجاز
o.b = 3;                       // اضافه کردن کلید ممنوع
console.log(o);
۳

Set: مجموعه‌ی بدون تکرار

کد · قابل اجراjs
const s = new Set([1, 2, 2, 3, 3]);
s.add(4);
console.log(s.has(2), s.size, [...s]);
const unique = [...new Set(["a", "b", "a"])];
console.log(unique);
۴

Map: کلید و مقدار با هر نوع کلید

کد · قابل اجراjs
const m = new Map();
m.set("name", "Rayvo").set(1, "عدد");
console.log(m.get("name"), m.size, m.has(1));
for (const [k, v] of m) console.log(k, "→", v);
کی Map؟

وقتی کلیدها داینامیک یا غیر متنی‌اند و ترتیب اضافه شدن مهم است. برای توصیف یک چیز ثابت (مثل کاربر) آبجکت ساده بهتر است.
