Destructuring، Spread و Rest

هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. Destructuring آرایه
  2. Destructuring آبجکت
  3. Spread
  4. Rest
  5. تمرین‌ها
۱

Destructuring آرایه

کد · قابل اجراjs
const [first, second, ...others] = [10, 20, 30, 40];
console.log(first, second, others);
let a = 1, b = 2;
[a, b] = [b, a];   // جابه‌جایی بدون متغیر کمکی
console.log(a, b);
۲

Destructuring آبجکت

در آبجکت نام کلید مهم است، نه ترتیب.

کد · قابل اجراjs
const user = { name: "Sara", age: 24, city: "Shiraz" };
const { name, age: years, country = "Iran" } = user;
console.log(name, years, country);

const show = ({ name, city }) => `${name} از ${city}`;
console.log(show(user));
۳

Spread

سه نقطه موقع باز کردن یک آرایه یا آبجکت است.

کد · قابل اجراjs
const a1 = [1, 2], a2 = [3, 4];
console.log([...a1, ...a2, 5]);
const base = { theme: "dark", lang: "fa" };
console.log({ ...base, lang: "en" });   // کلید بعدی غالب است
console.log(Math.max(...[3, 9, 4]));
۴

Rest

همان سه نقطه موقع جمع کردن باقیمانده است: در پارامتر تابع یا سمت چپ تساوی.

کد · قابل اجراjs
const user = { name: "Sara", age: 24, city: "Shiraz" };
const { name: n, ...rest } = user;
console.log(n, rest);
راه تشخیص

اگر سمت راست تساوی یا داخل آرایه‌ی جدید است، Spread است. اگر در پارامتر یا سمت چپ تساوی است، Rest است.
