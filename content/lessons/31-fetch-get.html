API چیست؟

API رابط گفتگوی برنامه‌ها با هم است. مثل گارسون رستوران: تو سفارش می‌دهی (درخواست) و آشپزخانه‌ی سرور غذا را آماده می‌کند و جواب می‌دهد. بیشتر API ها به سبک REST کار می‌کنند و عملیات را با متد HTTP مشخص می‌کنند (به آن‌ها CRUD هم می‌گویند):

  • GET: خواندن داده (Read)
  • POST: ساختن داده‌ی جدید (Create)
  • PUT و PATCH: ویرایش کامل و ویرایش بخشی (Update)
  • DELETE: حذف (Delete)
۲

اولین درخواست GET

fetch یک Promise می‌دهد و جواب سرور در دو مرحله می‌رسد: اول هدرها و وضعیت، بعد بدنه که با res.json() خوانده می‌شود. مثال‌ها از API آزمایشی jsonplaceholder استفاده می‌کنند و نیاز به اینترنت دارند.

کد (HTML و JS) · قابل اجراhtml
<button id="b">دریافت ۳ پست</button>
<ul id="l"></ul>
<p id="s"></p>
<script>
document.getElementById("b").onclick = async () => {
  const s = document.getElementById("s");
  const l = document.getElementById("l");
  s.textContent = "در حال دریافت...";
  l.textContent = "";
  try {
    const res = await fetch("https://jsonplaceholder.typicode.com/posts?_limit=3");
    if (!res.ok) throw new Error("خطای سرور: " + res.status);
    const posts = await res.json();
    posts.forEach((p) => {
      const li = document.createElement("li");
      li.textContent = p.title;
      l.append(li);
    });
    s.textContent = "";
  } catch (err) {
    s.textContent = "دریافت نشد: " + err.message;
  }
};
</script>
مهم‌ترین نکته‌ی Fetch

فقط وقتی ارتباط شبکه قطع باشد Promise رد می‌شود. جواب ۴۰۴ یا ۵۰۰ سرور خطا حساب نمی‌شود و باید خودت res.ok را چک کنی.

کد (HTML و JS) · قابل اجراhtml
<button id="b">درخواست به آدرس ناموجود</button>
<p id="s"></p>
<script>
document.getElementById("b").onclick = async () => {
  const s = document.getElementById("s");
  try {
    const res = await fetch("https://jsonplaceholder.typicode.com/posts/999999");
    s.textContent = "ok=" + res.ok + " ، status=" + res.status;
  } catch (e) {
    s.textContent = "اتصال برقرار نشد: " + e.message;
  }
};
</script>

قواعد JSON

کلیدها و رشته‌ها با دابل‌کوتیشن، بدون ویرگول آخر، بدون کامنت و بدون تابع. اگر res.json() خطا داد، جواب سرور JSON معتبر نبوده است.

۴

الگوی آماده برای پروژه‌ها

کدjs
async function getJSON(url) {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}
