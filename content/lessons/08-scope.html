Scope، Hoisting و Closure

هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

۱

Scope یعنی محدوده‌ی دیده شدن

متغیری که داخل { } با let یا const تعریف شود فقط همان‌جا زندگی می‌کند. متغیر بیرونی را همه جا می‌شود دید.

کد · قابل اجراjs
const global = "بیرونی";
function test() {
  const local = "داخلی";
  console.log(global, local);
}
test();
try { console.log(local); } catch (e) { console.log("خطا:", e.message); }
۲

Hoisting

جاوااسکریپت قبل از اجرا، تعریف‌ها را بالا می‌کشد. تابع‌های معمولی را می‌شود قبل از تعریف صدا زد، اما let و const قبل از تعریف خطا می‌دهند و var مقدار undefined دارد.

کد · قابل اجراjs
console.log(hello());        // کار می‌کند
function hello() { return "سلام"; }
console.log(x);              // undefined
var x = 5;
try { console.log(y); } catch (e) { console.log("خطا:", e.name); }
let y = 5;
توصیه

از var استفاده نکن. let و const رفتار قابل پیش‌بینی‌تری دارند.

۳

Closure

تابع داخلی همیشه به متغیرهای تابع بیرونی خود دسترسی دارد، حتی بعد از تمام شدن تابع بیرونی. این روش برای ساخت متغیر خصوصی عالی است.

کد · قابل اجراjs
function makeCounter() {
  let count = 0;
  return () => ++count;
}
const c1 = makeCounter();
console.log(c1(), c1(), c1());   // 1 2 3
const c2 = makeCounter();
console.log(c2());               // 1 (مستقل)

تمرین‌ها

تمرین ۱

شمارنده‌ای بساز که با هر بار صدا زدن ۲ تا اضافه شود

دیدن پاسخ
کد · قابل اجراjs
function counter() {
  let n = 0;
  return () => (n += 2);
}
const c = counter();
console.log(c(), c(), c());
تمرین ۲

چالش: تابعی بساز که اسم را یک بار بگیرد و بعد با هر صدا زدن «سلام اسم» برگرداند

دیدن پاسخ
کد · قابل اجراjs
const greeter = (name) => () => `سلام ${name}`;
console.log(greeter("Rayvo")());
