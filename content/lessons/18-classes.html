کلاس‌ها و Constructor

هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

۱

چرا کلاس؟

وقتی چند آبجکت هم‌شکل می‌خواهی (۱۰۰ کاربر، ۵۰ محصول)، کلاس یک قالب است و هر آبجکت یک نمونه (Instance) از آن.

کد · قابل اجراjs
class User {
  constructor(name, age) {   // هنگام new اجرا می‌شود
    this.name = name;
    this.age = age;
  }
  greet() {
    return `سلام، من ${this.name} هستم`;
  }
  birthday() {
    this.age++;
  }
}
const u1 = new User("Ali", 25);
const u2 = new User("Sara", 30);
u1.birthday();
console.log(u1.greet(), u1.age);
console.log(u2);
console.log(u1 instanceof User);
۲

نکات مهم

constructor همیشه همین نام را دارد. بدون new نمی‌شود کلاس را صدا زد و متدها بین همه‌ی نمونه‌ها مشترک‌اند (در حافظه فقط یک بار ذخیره می‌شوند).

اشتباه رایج

یادت نرود داخل constructor و متدها برای دسترسی به ویژگی‌ها this. بنویسی. بدون this، آن متغیر فقط یک متغیر محلی است.

۳

مثال کاربردی: سبد خرید

کد · قابل اجراjs
class Cart {
  constructor() { this.items = []; }
  add(name, price) { this.items.push({ name, price }); return this; }
  total() { return this.items.reduce((s, i) => s + i.price, 0); }
}
const cart = new Cart();
cart.add("کتاب", 90).add("مداد", 10);
console.log(cart.total(), cart.items.length);

تمرین‌ها

تمرین ۱

کلاس Product با name و price و متد discount(percent) که قیمت جدید را برگرداند

دیدن پاسخ
کد · قابل اجراjs
class Product {
  constructor(name, price) { this.name = name; this.price = price; }
  discount(p) { return this.price - (this.price * p) / 100; }
}
console.log(new Product("لپ‌تاپ", 1000).discount(10));
تمرین ۲

کلاس Counter با increment و reset

دیدن پاسخ
کد · قابل اجراjs
class Counter {
  constructor() { this.n = 0; }
  increment() { this.n++; return this; }
  reset() { this.n = 0; }
}
const c = new Counter();
console.log(c.increment().increment().n);
