Typed.js: افکت تایپ

افکت «متن در حال تایپ شدن» برای هیروی سایت‌های شخصی و شرکتی بسیار محبوب است. در پروژه‌ی سایت تک‌صفحه‌ای خودت آن را دستی نوشتی؛ حالا کتابخانه‌ی Typed.js همان را با گزینه‌های بیشتر و چند خط کد انجام می‌دهد.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. نصب
  2. استفاده‌ی پایه
  3. گزینه‌های مهم
  4. تمرین‌ها
۱

نصب

در این صفحه برای اینکه نمونه‌ها بدون اینترنت و بدون وابستگی به CDN اجرا شوند، نسخه‌ی کتابخانه از خود سایت بارگیری می‌شود. در پروژه‌ی خودت یکی از این دو روش را به کار ببر:

روش ۱: CDN (فقط چند تگ در HTML)html
<script src="https://cdn.jsdelivr.net/npm/typed.js@2.1.0/dist/typed.umd.js"></script>
روش ۲: npm (برای پروژه‌هایی که با Vite یا Webpack ساخته می‌شوند)txt
npm install typed.js@2.1.0
یادآوری

ما نسخه‌ی ۲٫۱٫۰ را پین کرده‌ایم که مجوز MIT دارد. نسخه‌های جدیدتر مجوز متفاوتی دارند؛ قبل از استفاده در پروژه‌ی تجاری مجوز را بخوان.

۲

استفاده‌ی پایه

یک المنت خالی (معمولاً span) در HTML بگذار و آن را به new Typed(انتخابگر, گزینه‌ها) بده.

کد (HTML و JS) · قابل اجراhtml
<h2>من <span id="t"></span></h2>

<script src="/assets/vendor/typed.umd.js"></script>
<script>
new Typed("#t", {
  strings: ["برنامه‌نویس وب هستم", "جاوااسکریپت یاد می‌گیرم", "پروژه می‌سازم"],
  typeSpeed: 60,      // سرعت تایپ (میلی‌ثانیه)
  backSpeed: 30,      // سرعت پاک کردن
  backDelay: 1200,    // مکث قبل از پاک شدن
  loop: true,
});
</script>
۳

گزینه‌های مهم

  • strings: آرایه‌ی جمله‌ها
  • typeSpeed و backSpeed
  • startDelay: مکث قبل از شروع
  • loop: تکرار بی‌پایان
  • showCursor و cursorChar: نشانگر چشمک‌زن
  • smartBackspace: فقط قسمتی را پاک می‌کند که با جمله‌ی بعد فرق دارد
کنترل با کدjs
const typed = new Typed("#t", { strings: ["اول", "دوم"], typeSpeed: 50 });
typed.stop();      // توقف
typed.start();     // ادامه
typed.destroy();   // پاک کردن کامل
سئو و دسترس‌پذیری

برای دسترس‌پذیری، اگر متن مهمی با Typed.js می‌نویسی، همان متن را (یا جمله‌ی اول را) به‌صورت ثابت هم در HTML بگذار تا صفحه‌خوان‌ها و موتورهای جستجو آن را ببینند.

تمرین‌ها

تمرین ۱

در صفحه‌ی خودت هیرویی بساز که سه شغل مختلف را تایپ کند.

راهنمایی

سه رشته در strings و loop: true.

تمرین ۲

با showCursor: false و CSS، نشانگر خودت را بساز.

راهنمایی

یک span با border و انیمیشن blink کنار المنت بگذار.
