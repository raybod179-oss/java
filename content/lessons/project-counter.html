<script>
const valueEl = document.getElementById("value");
const stepEl = document.getElementById("step");
let count = 0;                       // تنها منبع حقیقت (state)

function render() {
  valueEl.textContent = count.toLocaleString("fa-IR");
  valueEl.className = "value " + (count > 0 ? "pos" : count < 0 ? "neg" : "");
}
function change(direction) {
  count += direction * Number(stepEl.value);
  render();
}
function reset() { count = 0; render(); }

document.getElementById("inc").addEventListener("click", () => change(1));
document.getElementById("dec").addEventListener("click", () => change(-1));
document.getElementById("reset").addEventListener("click", reset);
document.addEventListener("keydown", (e) => {
  if (e.key === "ArrowUp") change(1);
  else if (e.key === "ArrowDown") change(-1);
  else if (e.key.toLowerCase() === "r") reset();
});
render();
</script>

پوشه‌ی پروژه و اجرا

برای ساخت روی کامپیوتر خودت یک پوشه با این ساختار بساز:

ساختار پوشهtxt
counter/
├── index.html   ← ساختار صفحه (HTML)
├── style.css    ← ظاهر (CSS)
└── script.js    ← منطق (JavaScript)
چطور اجرا کنم؟

فایل index.html را در مرورگر باز کن، یا در VS Code با افزونه‌ی Live Server روی آن راست‌کلیک و «Open with Live Server» را بزن تا با هر ذخیره، صفحه خودکار تازه شود.

۳

قدم ۱: ساختار HTML

صفحه فقط سه چیز دارد: عدد، سه دکمه و یک select برای گام. به عدد id="value" می‌دهیم تا با جاوااسکریپت پیدایش کنیم. صفت aria-live="polite" باعث می‌شود صفحه‌خوان‌ها تغییر عدد را اعلام کنند، و aria-label روی دکمه‌های نمادی نام قابل فهم می‌دهد.

HTMLhtml
<div id="value" class="value" aria-live="polite">0</div>
<button id="inc" aria-label="زیاد کن">+</button>

قدم ۲: ظاهر با CSS

رنگ‌ها را با متغیرهای CSS (--a، --bg) تعریف کرده‌ایم تا تغییر تم فقط یک جا باشد. کلاس‌های pos و neg رنگ عدد را عوض می‌کنند و transition این تغییر را نرم می‌کند.

CSScss
.value.pos { color: #4ade80; }
.value.neg { color: #fb7185; }

قدم ۳: منطق با جاوااسکریپت

قلب پروژه یک متغیر ساده است: count. هر دکمه فقط count را عوض می‌کند و بعد render() را صدا می‌زند. هیچ‌وقت عدد را مستقیم از روی صفحه نمی‌خوانیم؛ صفحه فقط نمایش داده است. این الگو در همه‌ی پروژه‌های بزرگ (حتی React) تکرار می‌شود.

JavaScriptjs
function change(direction) {
  count += direction * Number(stepEl.value);
  render();
}

مفاهیمی که در این پروژه استفاده شد

این پروژه بخش‌هایی از درس‌های قبل را به هم وصل می‌کند. اگر جایی نفهمیدی، همان درس را دوباره بخوان:

  • متغیر و let (درس ۲)
  • انتخاب المنت و رویدادها (درس‌های ۲۲ و ۲۴)
  • تابع و Arrow Function (درس ۷)
  • عملگر سه‌تایی (درس ۵)
  • toLocaleString برای اعداد فارسی (درس ۹)
۷

اشتباه‌های رایج

مقدار select رشته است

نتیجه‌ی stepEl.value متن است، پس اگر Number() نزنی، ۵ + ۵ می‌شود «۵۵». همیشه ورودی فرم را تبدیل کن.

نوشتن onclick = change(1)

با پرانتز، تابع همان لحظه اجرا می‌شود. تابع را داخل یک Arrow Function بگذار.
