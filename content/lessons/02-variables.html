۱

متغیر یعنی چه؟

متغیر یک جعبه‌ی نام‌دار است که مقدار را داخلش نگه می‌داری تا بعداً استفاده کنی.

کد · قابل اجراjs
let age = 20;
age = 21; // مقدار قابل تغییر است
const city = "Tehran"; // ثابت است
console.log(age, city);
۲

تفاوت let و const

با let مقداری می‌سازی که بعداً عوض می‌شود. با const مقداری که قرار نیست دوباره انتساب شود. قاعده‌ی خوب: همیشه با const شروع کن و فقط وقتی لازم شد let بگذار.

کد · قابل اجراjs
const pi = 3.14;
try { pi = 3; } catch (e) { console.log("خطا:", e.message); }
نکته

با const می‌شود داخل آرایه یا آبجکت چیز اضافه کرد، چون خود متغیر عوض نمی‌شود، فقط محتوایش.

۳

قواعد نام‌گذاری

نام با حرف، _ یا $ شروع می‌شود، فاصله ندارد و از کلمات رزرو شده مثل let نیست. سبک رایج camelCase است، مثل userName.
