رویدادها: موس، کیبورد و فرم

رویداد یعنی اتفاقی که کاربر یا مرورگر ایجاد می‌کند: کلیک، حرکت موس، فشردن کلید، ارسال فرم. با addEventListener یک تابع به رویداد وصل می‌کنی تا هر وقت رخ داد اجرا شود.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. رویدادهای موس و آبجکت Event
  2. رویدادهای کیبورد و ورودی
  3. ارسال فرم و preventDefault
  4. تمرین‌ها
۱

رویدادهای موس و آبجکت Event

تابع شنونده یک آرگومان می‌گیرد که اطلاعات رویداد را دارد: نوع، مختصات، المنتی که رویداد از آن شروع شد و غیره.

کد (HTML و JS) · قابل اجراhtml
<div id="pad" style="height:90px;border:2px dashed #888;display:grid;place-items:center">موس را اینجا حرکت بده</div>
<p id="out"></p>
<script>
const pad = document.getElementById("pad");
const out = document.getElementById("out");
pad.addEventListener("mousemove", (e) => {
  out.textContent = "x: " + e.offsetX + "  y: " + e.offsetY;
});
pad.addEventListener("click", (e) => { out.textContent = "کلیک از نوع " + e.type; });
pad.addEventListener("mouseleave", () => { out.textContent = "موس خارج شد"; });
</script>

رویدادهای کیبورد و ورودی

کد (HTML و JS) · قابل اجراhtml
<input id="inp" placeholder="تایپ کن و Enter بزن">
<p id="out"></p>
<script>
const inp = document.getElementById("inp");
const out = document.getElementById("out");
inp.addEventListener("input", (e) => { out.textContent = "نوشتی: " + e.target.value; });
inp.addEventListener("keydown", (e) => {
  if (e.key === "Enter") out.textContent += "  ✓ Enter";
});
</script>

رویداد input با هر تغییر محتوا اجرا می‌شود (حتی کپی و پیست). رویداد change فقط وقتی فیلد را ترک کنی. برای کلیدها از e.key استفاده کن (مثل "Enter" یا "a")، نه کدهای قدیمی.

ارسال فرم و preventDefault

رفتار پیش‌فرض فرم، رفرش صفحه است. با e.preventDefault() جلویش را می‌گیری تا خودت داده را مدیریت کنی.

کد (HTML و JS) · قابل اجراhtml
<form id="f">
  <input id="name" placeholder="نام">
  <button>ارسال</button>
</form>
<p id="msg"></p>
<script>
document.getElementById("f").addEventListener("submit", (e) => {
  e.preventDefault();
  const name = document.getElementById("name").value.trim();
  document.getElementById("msg").textContent = name ? "خوش آمدی " + name : "نام را وارد کن";
});
</script>
اشتباه رایج

نوشتن btn.onclick = handler() با پرانتز، تابع را همان لحظه اجرا می‌کند. درست: btn.onclick = handler.

دیدن پاسخ

t.addEventListener("input", () => {
  document.getElementById("c").textContent = t.value.length + " / 100";
});
</script>

چالش: فرم ورود با بررسی ایمیل و حداقل ۶ کاراکتر رمز

دیدن پاسخ
کد (HTML و JS) · قابل اجراhtml
<form id="f"><input id="e" placeholder="ایمیل"><br><input id="p" type="password" placeholder="رمز"><br><button>ورود</button></form>
<p id="m"></p>
<script>
document.getElementById("f").addEventListener("submit", (ev) => {
  ev.preventDefault();
  const okMail = /^[\w.-]+@[\w.-]+\.\w+$/.test(document.getElementById("e").value);
  const okPass = document.getElementById("p").value.length >= 6;
  document.getElementById("m").textContent = okMail && okPass ? "ورود موفق" : "اطلاعات نامعتبر";
});
</script>
