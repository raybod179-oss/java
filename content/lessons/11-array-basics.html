آرایه‌ها: افزودن، حذف و جستجو

هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. افزودن و حذف
  2. splice و slice
  3. جستجو
  4. تبدیل و ترکیب
  5. تمرین‌ها
۱

افزودن و حذف

کد · قابل اجراjs
const a = [1, 2, 3];
a.push(4);       // آخر اضافه
a.unshift(0);    // اول اضافه
console.log(a);
console.log(a.pop(), a.shift());   // حذف از آخر و اول
console.log(a);
۲

splice و slice

splice خود آرایه را تغییر می‌دهد، اما slice کپی جدید می‌سازد.

کد · قابل اجراjs
const x = ["a", "b", "c", "d", "e"];
console.log(x.slice(1, 3), x);          // x دست نخورد
x.splice(1, 2);                         // از اندیس 1، دو عضو حذف
console.log(x);
x.splice(1, 0, "NEW");                  // درج بدون حذف
console.log(x);
۳

جستجو

کد · قابل اجراjs
const nums = [5, 12, 8, 130, 44];
console.log(nums.indexOf(8), nums.includes(99));
console.log(nums.find((n) => n > 10));        // اولین مورد: 12
console.log(nums.findIndex((n) => n > 10));
console.log(nums.at(-1));
۴

تبدیل و ترکیب

کد · قابل اجراjs
console.log([1, 2].concat([3, 4]));
console.log([1, [2, [3]]].flat(2));
console.log(["a", "b", "c"].join("-"));
console.log([1, 2, 3].with(1, 99));    // کپی جدید با تغییر
اشتباه رایج

کپی کردن با const b = a آرایه را کپی نمی‌کند، فقط یک نام دیگر برای همان آرایه می‌سازد. برای کپی از [...a] یا a.slice() استفاده کن.

تمرین‌ها

تمرین ۱

از آرایه‌ی [1,2,3,4,5] عدد ۳ را حذف کن

دیدن پاسخ
کد · قابل اجراjs
const a = [1, 2, 3, 4, 5];
a.splice(a.indexOf(3), 1);
console.log(a);
تمرین ۲

آرایه‌ی تو در تو [[1,2],[3,[4]]] را تخت کن

دیدن پاسخ
کد · قابل اجراjs
console.log([[1, 2], [3, [4]]].flat(2));
روش تمرین

اول خودت حل کن، بعد پاسخ را ببین و با راه‌حل خودت مقایسه کن. چند راه درست برای یک مسئله وجود دارد.
