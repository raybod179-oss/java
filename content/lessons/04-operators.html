حسابی و انتسابی

کد · قابل اجراjs
console.log(7 + 3, 7 - 3, 7 * 3, 7 / 2);
console.log(7 % 3);   // باقیمانده: 1
console.log(2 ** 5);  // توان: 32
let x = 10;
x += 5; x *= 2;
console.log(x);       // 30
۲

مقایسه‌ای: == و ===

علامت == قبل از مقایسه نوع‌ها را تبدیل می‌کند و نتیجه‌های عجیب می‌دهد. در تمام پروژه‌ها === بنویس.

کد · قابل اجراjs
console.log(5 == "5");   // true
console.log(5 === "5");  // false
console.log(10 > 3, 10 <= 3, 4 !== 5);
۳

منطقی و Nullish

&& یعنی و، || یعنی یا، ! یعنی نقیض. عملگر ?? فقط برای null و undefined مقدار پیش‌فرض می‌دهد.

کد · قابل اجراjs
const age = 20, hasId = true;
console.log(age >= 18 && hasId);
console.log(0 || 100);   // 100
console.log(0 ?? 100);   // 0
console.log(null ?? "پیش‌فرض");

Prefix و Postfix

کد · قابل اجراjs
let a = 5;
console.log(a++); // 5 و بعد a می‌شود 6
console.log(a);   // 6
console.log(++a); // اول 7 می‌شود، بعد چاپ

چسباندن متن و NaN

کد · قابل اجراjs
console.log("سلام " + "دنیا");
const n = "Rayvo";
console.log(`خوش آمدی ${n}`);   // Template Literal
console.log("abc" * 2);          // NaN
console.log(Number.isNaN("abc" * 2));
نکته

NaN === NaN برابر false است. برای تشخیص آن از Number.isNaN استفاده کن.
