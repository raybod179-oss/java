هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

۱

متد: تابعی داخل آبجکت

داخل متد، this یعنی «آبجکتی که این متد را صدا زده».

کد · قابل اجراjs
const user = {
  name: "Ali",
  age: 25,
  greet() {
    return `سلام، من ${this.name} هستم`;
  },
  birthday() {
    this.age++;
    return this;      // برای زنجیره کردن
  },
};
console.log(user.greet());
console.log(user.birthday().birthday().age);   // 27
۲

this به صدا زننده بستگی دارد

مهم این است که تابع چگونه صدا زده شود، نه کجا نوشته شده. اگر متد را از آبجکت جدا کنی، this را گم می‌کند.

کد · قابل اجراjs
const car = {
  brand: "Peugeot",
  show() { return this.brand; },
};
console.log(car.show());          // Peugeot
const lost = car.show;
console.log(lost());              // this دیگر car نیست
۳

Arrow Function و this

Arrow Function this مخصوص خودش را ندارد و از محیط اطراف می‌گیرد. برای تابع‌های داخل یک متد (مثل forEach) عالی است.

کد · قابل اجراjs
const team = {
  name: "Rayvo",
  members: ["Sara", "Ali"],
  show() {
    this.members.forEach((m) => console.log(m, "در", this.name));
  },
};
team.show();
اشتباه رایج

نوشتن متد آبجکت به صورت Arrow (greet: () => this.name) درست کار نمی‌کند، چون this آبجکت نیست. برای متدهای آبجکت از شکل معمولی استفاده کن. اما برای رویدادها در DOM این موضوع را در فصل بعد می‌بینیم.

تمرین ۱

آبجکت counter بساز با value و متد increment که یکی اضافه کند

دیدن پاسخ
کد · قابل اجراjs
const counter = {
  value: 0,
  increment() { this.value++; return this; },
};
console.log(counter.increment().increment().value);
تمرین ۲

آبجکت product با name و price و متد describe بنویس

دیدن پاسخ
کد · قابل اجراjs
const product = {
  name: "کتاب",
  price: 90000,
  describe() { return `${this.name}: ${this.price} تومان`; },
};
console.log(product.describe());
