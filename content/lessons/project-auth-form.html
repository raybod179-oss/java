پروژه‌ی فرم ورود و ثبت‌نام

فرم ورود و ثبت‌نام با تعویض نرم بین دو حالت، نمایش و پنهان کردن رمز، نمایش خطاها و پیام موفقیت. این پروژه پایه‌ی کار با فرم است: submit، preventDefault و FormData. اعتبارسنجی کامل را در پروژه‌ی بعد تکمیل می‌کنیم.

<script>
const form = document.getElementById("form");
const msg = document.getElementById("msg");
const nameBox = document.getElementById("name-box");
const pass = document.getElementById("pass");
const go = document.getElementById("go");
let mode = "login";                                   // login | register

function setMode(m) {
  mode = m;
  document.getElementById("tab-login").classList.toggle("on", m === "login");
  document.getElementById("tab-register").classList.toggle("on", m === "register");
  nameBox.hidden = m === "login";
  go.textContent = m === "login" ? "ورود" : "ساخت حساب";
  pass.autocomplete = m === "login" ? "current-password" : "new-password";
  show("", "");
}
function show(text, type) { msg.textContent = text; msg.className = "msg " + type; }

document.getElementById("tab-login").addEventListener("click", () => setMode("login"));
document.getElementById("tab-register").addEventListener("click", () => setMode("register"));
document.getElementById("eye").addEventListener("click", (e) => {
  const hidden = pass.type === "password";
  pass.type = hidden ? "text" : "password";
  e.target.textContent = hidden ? "پنهان" : "نمایش";
});

form.addEventListener("submit", (e) => {
  e.preventDefault();                                  // جلوی رفرش صفحه
  const data = Object.fromEntries(new FormData(form)); // همه‌ی فیلدها در یک آبجکت
  if (mode === "register" && !data.name.trim()) return show("نام را وارد کن", "err");
  if (!data.email.includes("@")) return show("ایمیل معتبر نیست", "err");
  if (data.pass.length < 6) return show("رمز حداقل ۶ کاراکتر باشد", "err");
  show(mode === "login" ? "ورود موفق بود ✓" : "حساب ساخته شد ✓", "ok");
});
</script>

قدم ۱: ساختار فرم

هر فیلد یک label با صفت for دارد تا با کلیک روی متن، فیلد فوکوس بگیرد. به form صفت novalidate داده‌ایم تا اعتبارسنجی مرورگر دخالت نکند و پیام‌ها را خودمان با ظاهر دلخواه نشان بدهیم. صفت autocomplete به مرورگر کمک می‌کند رمز را پیشنهاد بدهد.

HTMLhtml
<form id="form" novalidate>
  <label for="email">ایمیل</label>
  <input id="email" name="email" type="email">
</form>

قدم ۲: دو حالت با یک فرم

به‌جای دو فرم جدا، یک متغیر mode نگه می‌داریم. تابع setMode فقط چند چیز را عوض می‌کند: فعال بودن تب، نمایش فیلد نام و متن دکمه. صفت hidden ساده‌ترین راه پنهان کردن است.

JavaScriptjs
function setMode(m) {
  mode = m;
  nameBox.hidden = m === "login";
  go.textContent = m === "login" ? "ورود" : "ساخت حساب";
}
۵

قدم ۳: خواندن فرم با FormData

در رویداد submit اول preventDefault() می‌زنیم. بعد new FormData(form) مقدار همه‌ی فیلدها را می‌خواند و Object.fromEntries آن را به یک آبجکت ساده تبدیل می‌کند: { email, pass, name }. پیام‌ها با return show(...) زود خارج می‌شوند (early return) تا کد تو در تو نشود.

JavaScriptjs
const data = Object.fromEntries(new FormData(form));
if (data.pass.length < 6) return show("رمز کوتاه است", "err");

مفاهیمی که در این پروژه استفاده شد

این پروژه بخش‌هایی از درس‌های قبل را به هم وصل می‌کند. اگر جایی نفهمیدی، همان درس را دوباره بخوان:

  • رویداد submit و preventDefault (درس ۲۴)
  • Destructuring و آبجکت (درس‌های ۳ و ۱۳)
  • Object.entries و FormData (درس ۱۴)
  • trim و includes برای رشته‌ها (درس ۹)

اشتباه‌های رایج

فراموش کردن type="button"

دکمه‌ای داخل فرم که type ندارد، فرم را submit می‌کند. دکمه‌ی «نمایش رمز» و تب‌ها باید type="button" باشند.

اعتبارسنجی فقط سمت کاربر

این اعتبارسنجی برای تجربه‌ی بهتر است، نه امنیت. سرور باید دوباره همه‌چیز را بررسی کند.
