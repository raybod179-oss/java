call، apply و bind

این سه متد اجازه می‌دهند خودت تعیین کنی this چه باشد.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. call و apply
  2. bind
  3. تمرین‌ها
۱

call و apply

هر دو تابع را همان لحظه اجرا می‌کنند. call آرگومان‌ها را جدا جدا می‌گیرد و apply به صورت آرایه.

کد · قابل اجراjs
function intro(city, job) {
  return `${this.name} از ${city}، ${job}`;
}
const a = { name: "Sara" };
console.log(intro.call(a, "Shiraz", "طراح"));
console.log(intro.apply(a, ["Tabriz", "برنامه‌نویس"]));
۲

bind

bind تابع را اجرا نمی‌کند، بلکه نسخه‌ی جدیدی با this ثابت می‌سازد. راه‌حل مشکل گم شدن this همین است.

کد · قابل اجراjs
const car = {
  brand: "Peugeot",
  show() { return this.brand; },
};
const lost = car.show;
const fixed = lost.bind(car);
console.log(fixed());   // Peugeot

function mul(a, b) { return a * b; }
const double = mul.bind(null, 2);   // آرگومان اول از قبل پر شد
console.log(double(10));
خلاصه

call و apply «همین الان اجرا کن»، bind «بعداً اجرا می‌کنم، this همین باشد».

★

تمرین‌ها

تمرین ۱

با call تابعی را روی آبجکت دیگری اجرا کن

دیدن پاسخ
کد · قابل اجراjs
function hi() { return "سلام " + this.name; }
console.log(hi.call({ name: "Rayvo" }));
تمرین ۲

با bind تابع triple بساز که عدد را سه برابر کند

دیدن پاسخ
کد · قابل اجراjs
const mul = (a, b) => a * b;
const triple = mul.bind(null, 3);
console.log(triple(7));
