پروژه‌ی مودال باکس

مودال (پنجره‌ی بازشو) در تقریباً هر سایتی هست: فرم ورود، تأیید حذف، پیام. در این پروژه یک مودال حرفه‌ای می‌سازی که با دکمه، کلیک روی پس‌زمینه و کلید Esc بسته می‌شود، اسکرول صفحه را قفل می‌کند و فوکوس را درست مدیریت می‌کند. بیش از یک مودال هم می‌توانی داشته باشی، بدون تکرار کد.

<script>
let lastFocus = null;

function openModal(id) {
  const modal = document.getElementById(id);
  if (!modal) return;
  lastFocus = document.activeElement;        // بعد از بستن، فوکوس برگردد
  modal.classList.add("open");
  modal.setAttribute("aria-hidden", "false");
  document.body.classList.add("lock");       // قفل اسکرول صفحه
  const first = modal.querySelector("button");
  if (first) first.focus();
}
function closeModal(modal) {
  modal.classList.remove("open");
  modal.setAttribute("aria-hidden", "true");
  if (!document.querySelector(".modal.open")) document.body.classList.remove("lock");
  if (lastFocus) lastFocus.focus();
}

// Event Delegation: یک شنونده برای همه‌ی دکمه‌ها
document.addEventListener("click", (e) => {
  const opener = e.target.closest("[data-open]");
  if (opener) return openModal(opener.dataset.open);
  const closer = e.target.closest("[data-close]");
  if (closer) return closeModal(closer.closest(".modal"));
  if (e.target.classList.contains("modal")) closeModal(e.target);   // کلیک روی پس‌زمینه
});
document.addEventListener("keydown", (e) => {
  if (e.key === "Escape") document.querySelectorAll(".modal.open").forEach(closeModal);
});
</script>

فایل index.html را در مرورگر باز کن، یا در VS Code با افزونه‌ی Live Server روی آن راست‌کلیک و «Open with Live Server» را بزن تا با هر ذخیره، صفحه خودکار تازه شود.

قدم ۱: ساختار و صفت‌های دسترس‌پذیری

هر مودال یک div با role="dialog" است. صفت aria-modal به صفحه‌خوان می‌گوید بقیه‌ی صفحه فعلاً غیرفعال است. دکمه‌ها با data-open="شناسه" و data-close علامت‌گذاری شده‌اند؛ پس برای ده مودال هم یک کد کافی است.

HTMLhtml
<button data-open="m-info">درباره‌ی دوره</button>
<div class="modal" id="m-info" role="dialog" aria-modal="true">…</div>
۴

قدم ۲: مخفی و نمایان با CSS

مودال به‌طور پیش‌فرض display:none است و کلاس open آن را grid می‌کند؛ با place-items:center وسط صفحه می‌نشیند. position:fixed و inset:0 کل صفحه را می‌پوشاند و پس‌زمینه‌ی تیره می‌سازد.

CSScss
.modal { position: fixed; inset: 0; display: none; place-items: center; }
.modal.open { display: grid; }
۵

قدم ۳: باز و بسته کردن

دو تابع openModal و closeModal همه‌ی کار را می‌کنند. نکته‌ی حرفه‌ای: قبل از باز شدن، المنتی که فوکوس داشت را نگه می‌داریم تا بعد از بستن، فوکوس به همان‌جا برگردد؛ کاربر کیبورد از وسط صفحه گم نمی‌شود. یک شنونده روی document (Event Delegation) برای همه‌ی دکمه‌ها کافی است.

JavaScriptjs
document.addEventListener("click", (e) => {
  const opener = e.target.closest("[data-open]");
  if (opener) return openModal(opener.dataset.open);
});

اشتباه‌های رایج

فراموش کردن قفل اسکرول

اگر overflow:hidden روی body نگذاری، با باز بودن مودال صفحه‌ی پشتش اسکرول می‌شود و حس بدی می‌دهد.

بستن مودال با هر کلیک داخل آن

شرط e.target.classList.contains("modal") فقط کلیک روی پس‌زمینه را می‌گیرد، نه کلیک داخل کادر.

چالش‌ها

چالش ۱

وقتی مودال باز است، کلید Tab فوکوس را داخل مودال نگه دارد (Focus Trap).

راهنمایی

همه‌ی دکمه‌های مودال را بگیر و روی Tab در آخرین، فوکوس را به اولی ببر.

چالش ۲

مودالی بساز که داخلش فرم باشد و بعد از ارسال بسته شود.

راهنمایی

در رویداد submit از preventDefault و بعد closeModal استفاده کن.

چالش ۳

انیمیشن بسته شدن اضافه کن.

راهنمایی

اول کلاس closing بده و بعد از پایان انیمیشن (animationend) کلاس open را بردار.

روش کار

هر چالش را روی نسخه‌ی خودت انجام بده. با اضافه کردن همین قابلیت‌ها، پروژه یک نمونه‌کار واقعی برای پورتفولیوی تو می‌شود.
