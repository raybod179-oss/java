کد · قابل اجراjs

slice و substring

هر دو بخشی از متن را جدا می‌کنند. slice اندیس منفی را می‌فهمد و substring نه.

کد · قابل اجراjs
const w = "JavaScript";
console.log(w.slice(0, 4));    // Java
console.log(w.slice(-6));      // Script
console.log(w.substring(4, 10));
۴

split، padStart و padEnd

کد · قابل اجراjs
console.log("a,b,c".split(","));
console.log("hello".split(""));
console.log("7".padStart(3, "0"));   // 007
console.log("ok".padEnd(5, "."));    // ok...
console.log((1234567).toLocaleString("en-US"));
اشتباه رایج

نوشتن s.toUpperCase() بدون ذخیره‌ی نتیجه فایده ندارد، چون s عوض نمی‌شود. نتیجه را در متغیر بریز.
