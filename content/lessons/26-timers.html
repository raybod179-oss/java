تایمرها: setTimeout و setInterval

هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. setTimeout: یک بار، بعد از تأخیر
  2. setInterval و clearInterval
  3. شمارش معکوس
  4. تمرین‌ها
۱

setTimeout: یک بار، بعد از تأخیر

کد (HTML و JS) · قابل اجراhtml
<button id="b">پیام را بعد از ۲ ثانیه نشان بده</button>
<p id="out"></p>
<script>
document.getElementById("b").onclick = () => {
  document.getElementById("out").textContent = "منتظر باش...";
  setTimeout(() => {
    document.getElementById("out").textContent = "تمام شد!";
  }, 2000);
};
</script>
۲

setInterval و clearInterval

setInterval هر چند میلی‌ثانیه یک بار تابع را اجرا می‌کند تا وقتی که با clearInterval متوقفش کنی. شناسه‌ی برگشتی را نگه دار.

کد (HTML و JS) · قابل اجراhtml
<h3 id="n">0</h3>
<button id="s">شروع</button>
<button id="p">توقف</button>
<script>
let id = null, n = 0;
document.getElementById("s").onclick = () => {
  if (id) return;               // از شروع دوباره جلوگیری کن
  id = setInterval(() => { document.getElementById("n").textContent = ++n; }, 1000);
};
document.getElementById("p").onclick = () => { clearInterval(id); id = null; };
</script>
اشتباه رایج

اگر دو بار دکمه‌ی شروع را بزنی و شناسه‌ی قبلی را نگه نداری، دو تایمر هم‌زمان کار می‌کنند و دیگر نمی‌توانی اولی را متوقف کنی. همیشه قبل از شروع چک کن.

شمارش معکوس

کد (HTML و JS) · قابل اجراhtml
<h2 id="t">10</h2>
<button id="go">شروع</button>
<script>
document.getElementById("go").onclick = () => {
  let left = 10;
  const id = setInterval(() => {
    left--;
    document.getElementById("t").textContent = left;
    if (left === 0) { clearInterval(id); document.getElementById("t").textContent = "تمام!"; }
  }, 1000);
};
</script>

</script>
