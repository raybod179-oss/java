Getter، Setter و Static

هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. Getter و Setter
  2. اعتبارسنجی با Setter
  3. Static
  4. تمرین‌ها
۱

Getter و Setter

با get و set یک متد را مثل ویژگی صدا می‌زنی، یعنی بدون پرانتز. مناسب محاسبه‌ی خودکار و اعتبارسنجی هنگام مقداردهی.

کد · قابل اجراjs
class Person {
  constructor(first, last) { this.first = first; this.last = last; }
  get fullName() { return `${this.first} ${this.last}`; }
  set fullName(v) { [this.first, this.last] = v.split(" "); }
}
const p = new Person("Ali", "Karimi");
console.log(p.fullName);
p.fullName = "Sara Ahmadi";
console.log(p.first, p.last);
۲

اعتبارسنجی با Setter

کد · قابل اجراjs
class Product {
  #price = 0;
  get price() { return this.#price; }
  set price(v) {
    if (typeof v !== "number" || v < 0) {
      console.log("قیمت نامعتبر");
      return;
    }
    this.#price = v;
  }
}
const pr = new Product();
pr.price = -5;
pr.price = 2000;
console.log(pr.price);
۳

Static

متد یا ویژگی static به خود کلاس تعلق دارد، نه نمونه‌ها. برای ابزارهای کمکی و شمارنده‌ی کلی مناسب است.

کد · قابل اجراjs
class MathTool {
  static square(n) { return n * n; }
}
console.log(MathTool.square(9));

class User {
  static count = 0;
  constructor(name) { this.name = name; User.count++; }
}
new User("a"); new User("b");
console.log(User.count);   // 2
اشتباه رایج

متد static را روی نمونه صدا نمی‌زنند: new MathTool().square(2) خطا می‌دهد. با نام کلاس صدا بزن.

تمرین ۱

کلاس Rectangle با getter برای area

دیدن پاسخ
کد · قابل اجراjs
class Rectangle {
  constructor(w, h) { this.w = w; this.h = h; }
  get area() { return this.w * this.h; }
}
console.log(new Rectangle(3, 4).area);
تمرین ۲

کلاس Order با شمارنده‌ی static که شماره‌ی سفارش بدهد

دیدن پاسخ
کد · قابل اجراjs
class Order {
  static last = 0;
  constructor() { this.id = ++Order.last; }
}
console.log(new Order().id, new Order().id);
