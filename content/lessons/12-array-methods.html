map، filter، reduce و sort

این متدها مهم‌ترین ابزار کار با داده در جاوااسکریپت‌اند و در هر پروژه‌ای می‌بینی‌شان. همه تابعی می‌گیرند که روی هر عضو اجرا می‌شود.

۱

forEach و map

forEach فقط می‌چرخد و چیزی برنمی‌گرداند. map یک آرایه‌ی جدید با نتیجه‌ی هر عضو می‌سازد.

کد · قابل اجراjs
const nums = [1, 2, 3];
nums.forEach((n) => console.log("عضو:", n));
const doubled = nums.map((n) => n * 2);
console.log(doubled);
۲

filter

فقط اعضایی که شرط را داشته باشند نگه می‌دارد.

کد · قابل اجراjs
const products = [
  { name: "کتاب", price: 90 },
  { name: "مداد", price: 10 },
  { name: "لپ‌تاپ", price: 5000 },
];
const cheap = products.filter((p) => p.price < 100);
console.log(cheap.map((p) => p.name));
۳

reduce

کل آرایه را به یک مقدار تبدیل می‌کند: مجموع، شمارش، گروه‌بندی.

کد · قابل اجراjs
const products = [{ name: "کتاب", price: 90 }, { name: "مداد", price: 10 }, { name: "لپ‌تاپ", price: 5000 }];
const total = products.reduce((sum, p) => sum + p.price, 0);
console.log(total);
const count = ["a", "b", "a", "c", "a"].reduce((acc, ch) => {
  acc[ch] = (acc[ch] || 0) + 1;
  return acc;
}, {});
console.log(count);

some و every

کد · قابل اجراjs
console.log([1, 5, 9].some((n) => n > 8));    // حداقل یکی
console.log([1, 5, 9].every((n) => n > 0));    // همه
۵

sort و reverse

دام معروف

sort بدون ورودی اعداد را مثل متن مرتب می‌کند و 10 را قبل از 2 می‌گذارد. برای عدد حتماً تابع مقایسه بده.

کد · قابل اجراjs
const n = [10, 2, 33, 4];
console.log([...n].sort());                 // اشتباه
console.log([...n].sort((a, b) => a - b));  // صعودی
console.log(n.toSorted((a, b) => b - a));   // نزولی، بدون تغییر n
console.log(n.toReversed());
۶

زنجیره‌ی متدها

کد · قابل اجراjs
const products = [{ name: "کتاب", price: 90 }, { name: "مداد", price: 10 }, { name: "لپ‌تاپ", price: 5000 }];
const result = products
  .filter((p) => p.price > 50)
  .map((p) => p.name)
  .join("، ");
console.log(result);
