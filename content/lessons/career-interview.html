آمادگی مصاحبه‌ی جاوااسکریپت

در مصاحبه‌ی فرانت‌اند معمولاً سه چیز بررسی می‌شود: مفاهیم زبان (تو چقدر می‌دانی)، حل مسئله‌ی کوچک با کد، و پروژه‌هایت. این درس پرسش‌های پرتکرار را با پاسخ کوتاه، تمرین پیش‌بینی خروجی و مسئله‌های کدنویسی جمع کرده است. اول خودت جواب بده، بعد پاسخ را ببین.

۱

مصاحبه چطور است؟

بیشتر مصاحبه‌های فنی این شکل را دارند: ۵ تا ۱۰ دقیقه آشنایی و پروژه‌ها، ۲۰ تا ۳۰ دقیقه سؤال‌های مفهومی، یک مسئله‌ی کدنویسی کوچک و در پایان سؤال‌های تو. نکته‌ی اصلی: بلند فکر کن. اگر پاسخ را نمی‌دانی، بگو چه فکر می‌کنی و از کجا شروع می‌کنی؛ همین مهارت حل مسئله‌ات را نشان می‌دهد.

۲

سؤال‌های مفهومی پرتکرار

سؤال

تفاوت var، let و const؟

پاسخ کوتاه

var محدوده‌ی تابع دارد و hoist می‌شود (مقدار اولیه undefined). let و const محدوده‌ی بلوک دارند و قبل از تعریف در «منطقه‌ی مرده» (TDZ) خطا می‌دهند. const انتساب دوباره را ممنوع می‌کند، نه تغییر محتوای آبجکت را.

سؤال

== با === چه فرقی دارد؟

پاسخ کوتاه== قبل از مقایسه نوع‌ها را تبدیل می‌کند (5 == "5" درست است)، ولی === نوع و مقدار را بدون تبدیل مقایسه می‌کند. توصیه: همیشه ===.
سؤال

Closure چیست؟

پاسخ کوتاه

تابعی که به متغیرهای محدوده‌ای که در آن ساخته شده دسترسی دارد، حتی بعد از تمام شدن آن محدوده. کاربرد: متغیر خصوصی، شمارنده، تابع‌سازها و debounce.

سؤال

this چطور مقدار می‌گیرد؟

پاسخ کوتاه

مقدارش به نحوه‌ی صدا زدن تابع بستگی دارد: در متد آبجکت همان آبجکت، با new نمونه‌ی جدید، با call/apply/bind مقدار دلخواه. Arrow Function this خودش را ندارد و از محیط اطراف می‌گیرد.

سؤال

Event Loop را توضیح بده.

پاسخ کوتاه

جاوااسکریپت تک‌نخی است. کدهای همزمان در Call Stack اجرا می‌شوند؛ کارهای ناهمزمان (تایمر، fetch) به مرورگر سپرده می‌شوند و نتیجه‌شان در صف می‌ایستد. وقتی Stack خالی شد، اول صف Microtask (Promise) و بعد صف Macrotask (setTimeout) اجرا می‌شود.

سؤال

Promise و async/await چه فرقی دارند؟

پاسخ کوتاه

async/await نوشتار ساده‌تری روی همان Promise است. تابع async همیشه Promise برمی‌گرداند و await منتظر آن می‌ماند. برای هم‌زمانی از Promise.all و برای نتیجه‌ی همه‌ی حالت‌ها از allSettled استفاده کن.

سؤال

Event Delegation چیست و چرا مفید است؟

پاسخ کوتاه

به‌جای وصل کردن شنونده به هر فرزند، یک شنونده به پدر می‌دهی و با e.target.closest() فرزند را پیدا می‌کنی. حافظه‌ی کمتر و کار کردن روی المنت‌هایی که بعداً ساخته می‌شوند.

سؤال

کپی سطحی (shallow) و عمیق (deep)؟

پاسخ کوتاه

spread و Object.assign فقط سطح اول را کپی می‌کنند؛ آبجکت‌های داخلی مشترک می‌مانند. کپی عمیق: structuredClone(obj). روش JSON.parse(JSON.stringify()) تابع، Date و undefined را خراب می‌کند.

سؤال

تفاوت debounce و throttle؟

پاسخ کوتاه

debounce بعد از آخرین رویداد و یک مکث اجرا می‌شود (جستجوی زنده). throttle حداکثر هر چند میلی‌ثانیه یک‌بار اجرا می‌شود (اسکرول و تغییر اندازه).

سؤال

null با undefined؟

پاسخ کوتاهundefined یعنی «مقدار داده نشده»؛ null یعنی «عمداً خالی». typeof null برابر "object" است که یک باگ قدیمی زبان است.

مسئله‌های کدنویسی

مسئله‌های کوچکی که معمولاً در مصاحبه می‌پرسند. هرکدام را اول خودت بنویس، بعد با راه‌حل مقایسه کن.

تمرین ۱

رشته را معکوس کن و بررسی کن پالیندروم است یا نه.

راه‌حل
کد · قابل اجراjs
const reverse = (s) => [...s].reverse().join("");
const isPalindrome = (s) => { const t = s.toLowerCase().replace(/[^a-z0-9]/g, ""); return t === reverse(t); };
console.log(reverse("rayvo"), isPalindrome("A man, a plan, a canal: Panama"));

تمرین ۴

دو عدد آرایه را پیدا کن که مجموعشان برابر هدف باشد (Two Sum) در یک پیمایش.

راه‌حل
کد · قابل اجراjs
function twoSum(nums, target) {
  const seen = new Map();                      // عدد ← اندیس
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }
  return null;
}
console.log(twoSum([2, 7, 11, 15], 9));

تمرین ۶

تابع debounce را از صفر بنویس.

راه‌حل
کد · قابل اجراjs
function debounce(fn, ms) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
}
const log = debounce((x) => console.log("اجرا شد با", x), 200);
log(1); log(2); log(3);
۵

پروژه‌ها و سؤال‌های رفتاری

مصاحبه‌کننده تقریباً همیشه درباره‌ی پروژه‌هایت می‌پرسد. برای هر پروژه‌ی پورتفولیو سه جواب آماده داشته باش:

  1. چه مسئله‌ای را حل می‌کند؟ (دو جمله)
  2. سخت‌ترین بخشش چه بود و چطور حلش کردی؟ (مثلاً race condition در جستجو و راه‌حل AbortController)
  3. اگر دوباره می‌ساختی چه چیزی را عوض می‌کردی؟

برای سؤال‌هایی مثل «یک باگ سخت را چطور حل کردی؟»، از قالب «موقعیت، کار، نتیجه» استفاده کن و روشی را که در درس «مدیریت خطا و دیباگ» دیدی توضیح بده.

★

چک‌لیست یک هفته‌ی قبل

  • پروژه‌هایت آنلاین‌اند و لینک‌ها کار می‌کنند.
  • هر پروژه را در یک دقیقه می‌توانی توضیح بدهی.
  • سؤال‌های مفهومی این درس را بلند و بدون نگاه کردن جواب داده‌ای.
  • دو تا سه مسئله را روی کاغذ یا ویرایشگر ساده حل کرده‌ای.
  • سؤال‌هایی برای پرسیدن از شرکت داری (تکنولوژی، تیم، مسیر رشد).
