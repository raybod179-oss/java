نتیجه‌ی نهایی و کد کامل

روی «اجرای زنده» بزن و با پروژه کار کن. کد کامل (CSS و HTML و JavaScript) همین‌جا هست؛ در بخش‌های بعد قدم‌به‌قدم توضیح داده شده. بهتر است اول خودت بسازی و فقط وقتی گیر کردی نگاه کنی.

کد کامل پروژه · قابل اجراhtml
<style>
:root{--bg:#f4f7fc;--card:#ffffff;--line:#d5deee;--text:#0e1b2e;--mut:#55688a;--a:#b45309}
[data-theme="dark"]{--bg:#070b16;--card:#0f1830;--line:#1d2b4d;--text:#e8f0ff;--mut:#8fa3c8;--a:#fbbf24}
*{box-sizing:border-box}
body{margin:0;min-height:100vh;display:grid;place-items:center;background:var(--bg);color:var(--text);font-family:Tahoma,Vazirmatn,sans-serif;padding:16px}
button{font:inherit;cursor:pointer;border:1px solid var(--line);background:var(--card);color:var(--text);border-radius:12px;padding:10px 18px}
button:hover{border-color:var(--a)}
button:focus-visible{outline:2px solid var(--a);outline-offset:2px}

.page{width:min(480px,100%)}

.card h2{margin:0 0 6px;font-size:16px;color:var(--a)}.card p{margin:0;color:var(--mut);line-height:1.9}

<div class="page">
  <header>
    <h1>تم تیره و روشن</h1>
    <button id="toggle" aria-pressed="false">🌙 تیره</button>
  </header>
  <div class="card"><h2>کارت اول</h2><p>همه‌ی رنگ‌ها از متغیرهای CSS می‌آیند.</p></div>
  <div class="card"><h2>کارت دوم</h2><p>انتخاب تو در مرورگر ذخیره می‌شود.</p></div>
</div>

<script>
const root = document.documentElement;
const button = document.getElementById("toggle");

function getSaved() {
  try { return localStorage.getItem("theme"); } catch (e) { return null; }
}
function save(theme) {
  try { localStorage.setItem("theme", theme); } catch (e) { /* مرورگر اجازه نداد */ }
}

const prefersDark = window.matchMedia && window.matchMedia("(prefers-color-scheme: dark)").matches;
let theme = getSaved() || (prefersDark ? "dark" : "light");   // اول انتخاب خود کاربر، بعد سیستم

function apply(t) {
  root.setAttribute("data-theme", t);
  button.textContent = t === "dark" ? "☀️ روشن" : "🌙 تیره";
  button.setAttribute("aria-pressed", String(t === "dark"));
}

button.addEventListener("click", () => {
  theme = theme === "dark" ? "light" : "dark";
  apply(theme);
  save(theme);
});
apply(theme);
</script>

پوشه‌ی پروژه و اجرا

برای ساخت روی کامپیوتر خودت یک پوشه با این ساختار بساز:

ساختار پوشهtxt
theme/
├── index.html   ← ساختار صفحه (HTML)
├── style.css    ← ظاهر (CSS)
└── script.js    ← منطق (JavaScript)
چطور اجرا کنم؟

فایل index.html را در مرورگر باز کن، یا در VS Code با افزونه‌ی Live Server روی آن راست‌کلیک و «Open with Live Server» را بزن تا با هر ذخیره، صفحه خودکار تازه شود.

۳

قدم ۱: رنگ‌ها را متغیر کن

همه‌ی رنگ‌های صفحه را فقط یک‌بار در :root تعریف می‌کنیم و در بقیه‌ی CSS با var(--bg) می‌خوانیم. برای تم تیره، همین متغیرها زیر انتخابگر [data-theme="dark"] دوباره مقدار می‌گیرند. جاوااسکریپت فقط یک صفت را عوض می‌کند و CSS بقیه را انجام می‌دهد.

CSScss
:root { --bg: #f4f7fc; --text: #0e1b2e; }
[data-theme="dark"] { --bg: #070b16; --text: #e8f0ff; }
body { background: var(--bg); color: var(--text); }
۴

قدم ۲: انتخاب اولیه

ترتیب تصمیم‌گیری مهم است: اگر کاربر قبلاً انتخاب کرده، همان را بگیر؛ وگرنه ببین سیستم‌عاملش تیره است یا نه (prefers-color-scheme). به این ترتیب بار اولی که وارد می‌شود هم تجربه‌ی درست دارد.

JavaScriptjs
let theme = getSaved() || (prefersDark ? "dark" : "light");
۵

قدم ۳: ذخیره‌ی انتخاب

localStorage ممکن است خطا بدهد (حالت خصوصی مرورگر یا iframe بدون اجازه)، برای همین getItem و setItem داخل try/catch هستند تا برنامه نشکند. در همین پیش‌نمایش زنده هم ذخیره‌سازی بسته است و برنامه بدون مشکل ادامه می‌دهد.

JavaScriptjs
try { localStorage.setItem("theme", theme); } catch (e) {}
۶

مفاهیمی که در این پروژه استفاده شد

این پروژه بخش‌هایی از درس‌های قبل را به هم وصل می‌کند. اگر جایی نفهمیدی، همان درس را دوباره بخوان:

  • متغیرهای CSS و صفت data-* (درس ۲۵)
  • localStorage و try/catch (درس‌های ۲۷ و ۳۰)
  • عملگر || برای مقدار پیش‌فرض (درس ۴)
  • matchMedia و BOM (درس ۲۷)
۷

اشتباه‌های رایج

چشمک زدن تم هنگام لود

اگر تم را بعد از لود صفحه بخوانی، کاربر لحظه‌ای تم اشتباه می‌بیند. در پروژه‌ی واقعی یک اسکریپت کوچک را در head بگذار.

ذخیره‌ی مقدار بولین

localStorage فقط رشته نگه می‌دارد؛ "false" در شرط truthy است! رشته‌های واضح مثل "dark" امن‌ترند.

★

چالش‌ها

چالش ۱

سه تم بساز: روشن، تیره و خودکار (طبق سیستم).

راهنمایی

مقدار "auto" را ذخیره کن و تغییرات matchMedia را با addEventListener("change") بشنو.

چالش ۲

تم را با انیمیشن دایره‌ای عوض کن.

راهنمایی

از document.startViewTransition استفاده کن (اگر مرورگر پشتیبانی کرد).

چالش ۳

رنگ اصلی را هم انتخاب‌پذیر کن.

راهنمایی

یک input type="color" بگذار و --a را با style.setProperty عوض کن.

روش کار

هر چالش را روی نسخه‌ی خودت انجام بده. با اضافه کردن همین قابلیت‌ها، پروژه یک نمونه‌کار واقعی برای پورتفولیوی تو می‌شود.
