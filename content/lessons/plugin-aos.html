AOS: انیمیشن با اسکرول

AOS (Animate On Scroll) هر المنتی را وقتی وارد دید شد با یک انیمیشن نشان می‌دهد؛ فقط با افزودن صفت data-aos به HTML. در پروژه‌ی سایت تک‌صفحه‌ای همین کار را با IntersectionObserver دستی انجام دادی و حالا نسخه‌ی آماده‌ی آن را می‌بینی.

۱

نصب

در این صفحه برای اینکه نمونه‌ها بدون اینترنت و بدون وابستگی به CDN اجرا شوند، نسخه‌ی کتابخانه از خود سایت بارگیری می‌شود. در پروژه‌ی خودت یکی از این دو روش را به کار ببر:

روش ۱: CDN (فقط چند تگ در HTML)html
<link rel="stylesheet" href="https://unpkg.com/aos@2.3.4/dist/aos.css">
<script src="https://unpkg.com/aos@2.3.4/dist/aos.js"></script>
روش ۲: npm (برای پروژه‌هایی که با Vite یا Webpack ساخته می‌شوند)txt
npm install aos
یادآوری

AOS هم CSS می‌خواهد هم JS؛ و باید یک‌بار AOS.init() را صدا بزنی.

۲

استفاده‌ی پایه

در پیش‌نمایش پایین، داخل کادر اسکرول کن تا هر بلوک با انیمیشن بیاید:

کد (HTML و JS) · قابل اجراhtml
<link rel="stylesheet" href="/assets/vendor/aos.css">
<style>
  body { overflow-x: hidden; }
  .box { height: 110px; margin: 50px 0; border-radius: 16px; display: grid; place-items: center;
         font-size: 20px; background: #fbbf24; color: #1a1204; }
</style>

<div class="box" data-aos="fade-up">fade-up</div>
<div class="box" data-aos="fade-right" data-aos-delay="150">fade-right + تأخیر</div>
<div class="box" data-aos="zoom-in" data-aos-duration="900">zoom-in</div>
<div class="box" data-aos="flip-left">flip-left</div>

<script src="/assets/vendor/aos.js"></script>
<script>AOS.init({ duration: 700, once: true, offset: 60 });</script>
۳

صفت‌ها و تنظیمات

  • data-aos: نوع انیمیشن (fade-up، fade-down، fade-left، zoom-in، flip-up، ...)
  • data-aos-delay و data-aos-duration: تأخیر و مدت (میلی‌ثانیه)
  • data-aos-easing: منحنی سرعت (ease-in-out)
  • تنظیم کلی در AOS.init: once (فقط یک‌بار)، offset (فاصله‌ی شروع)، duration
مراقب باش

انیمیشن‌های fade-right و fade-left المنت را موقتاً بیرون از صفحه می‌برند و می‌توانند اسکرول افقی بسازند. به body (یا کانتینر بیرونی) overflow-x: hidden بده.

بدان

اگر محتوا را بعداً با جاوااسکریپت می‌سازی (مثل لیست پروژه‌های API)، بعد از ساخت یک‌بار AOS.refresh() را صدا بزن تا المنت‌های جدید را بشناسد.
