متدهای Number

کد · قابل اجراjs
const n = 3.14159;
console.log(n.toFixed(2));            // "3.14" (رشته است)
console.log(Number.isInteger(5), Number.isInteger(5.5));
console.log(0.1 + 0.2);               // 0.30000000000000004
console.log((0.1 + 0.2).toFixed(2));
نکته

خطای 0.1 + 0.2 ربطی به جاوااسکریپت ندارد؛ کامپیوتر اعداد اعشاری را دودویی ذخیره می‌کند. برای پول، قیمت را به صورت عدد صحیح (ریال) نگه دار.

عدد تصادفی

Math.random() عددی بین ۰ و کمتر از ۱ می‌دهد. برای بازه‌ی مشخص این فرمول را حفظ کن:

کد · قابل اجراjs
const rand = (min, max) => Math.floor(Math.random() * (max - min + 1)) + min;
const r = rand(1, 6);
console.log(r >= 1 && r <= 6);   // true

تمرین ۱

دیدن پاسخ
کد · قابل اجراjs

تمرین ۲

تابعی بنویس که قیمت و درصد تخفیف بگیرد و قیمت نهایی گرد شده را بدهد

دیدن پاسخ
کد · قابل اجراjs
const final = (p, d) => Math.round(p - (p * d) / 100);
console.log(final(200000, 15));
روش تمرین

اول خودت حل کن، بعد پاسخ را ببین و با راه‌حل خودت مقایسه کن. چند راه درست برای یک مسئله وجود دارد.
