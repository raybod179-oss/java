Video.js: پخش‌کننده‌ی ویدیو

تگ ساده‌ی video در هر مرورگر شکل متفاوتی دارد. Video.js یک پخش‌کننده‌ی یکدست و قابل شخصی‌سازی می‌سازد: سرعت پخش، زیرنویس، کیفیت و رویدادهای کامل. برای دوره‌ی ویدیویی یا بخش آموزش در سایتت مناسب است.

۱

نصب

در این صفحه برای اینکه نمونه‌ها بدون اینترنت و بدون وابستگی به CDN اجرا شوند، نسخه‌ی کتابخانه از خود سایت بارگیری می‌شود. در پروژه‌ی خودت یکی از این دو روش را به کار ببر:

روش ۱: CDN (فقط چند تگ در HTML)html
<link href="https://cdn.jsdelivr.net/npm/video.js@8.24.2/dist/video-js.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/video.js@8.24.2/dist/video.min.js"></script>
روش ۲: npm (برای پروژه‌هایی که با Vite یا Webpack ساخته می‌شوند)txt
npm install video.js@8
یادآوری

ما نسخه‌ی ۸ را استفاده می‌کنیم. نسخه‌ی ۱۰ ساختار جدید و API متفاوتی دارد؛ نسخه را از مستندات رسمی بررسی کن.

۲

استفاده‌ی پایه

یک تگ video با کلاس video-js بساز و با videojs("شناسه", گزینه‌ها) آن را راه بینداز. ویدیوی نمونه‌ی زیر ۶ ثانیه است و روی همین سایت قرار دارد:

کد (HTML و JS) · قابل اجراhtml
<link rel="stylesheet" href="/assets/vendor/video-js.min.css">

<video id="player" class="video-js" controls preload="auto"
       poster="/assets/demo/poster.jpg" width="480" height="270">
  <source src="/assets/demo/sample.mp4" type="video/mp4">
</video>

<script src="/assets/vendor/video.min.js"></script>
<script>
const player = videojs("player", {
  fluid: true,                          // با عرض صفحه تنظیم شود
  playbackRates: [0.5, 1, 1.5, 2],      // منوی سرعت
});
player.on("ended", () => console.log("ویدیو تمام شد"));
</script>
۳

گزینه‌ها و کنترل با کد

  • controls، autoplay، loop، muted: همان صفت‌های استاندارد (autoplay معمولاً فقط همراه muted کار می‌کند)
  • poster: تصویر قبل از پخش
  • playbackRates: سرعت‌های قابل انتخاب
  • player.play()، pause()، currentTime()، volume(): متدها (توجه: متد هستند، نه ویژگی)
رویدادها و کنترلjs
player.on("timeupdate", () => {
  const percent = (player.currentTime() / player.duration()) * 100;
  console.log(Math.round(percent) + "٪ دیده شد");
});
player.currentTime(30);   // پرش به ثانیه‌ی ۳۰
player.volume(0.5);       // صدا
حجم

Video.js یک کتابخانه‌ی بزرگ‌تر است (حدود ۶۷۰ کیلوبایت). اگر فقط یک ویدیوی ساده لازم داری، تگ video با controls کافی و سریع‌تر است.
