BOM، LocalStorage و JSON

هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

  2. JSON

۱

BOM یعنی مدل مرورگر

آبجکت window بالاترین آبجکت مرورگر است و به بخش‌هایی دسترسی می‌دهد: location (آدرس)، history (تاریخچه)، navigator (اطلاعات مرورگر و دستگاه). این کدها را در کنسول F12 صفحه‌ی خودت امتحان کن:

کدjs
console.log(window.innerWidth, window.innerHeight);
console.log(location.href, location.hostname);
console.log(navigator.language, navigator.onLine);
history.back();   // برگشت به صفحه‌ی قبل
// location.href = "https://rayvo.vercel.app";  // رفتن به صفحه‌ی دیگر

دسترسی به موقعیت مکانی کاربر فقط پس از اجازه‌ی خودش ممکن است:

کدjs
navigator.geolocation.getCurrentPosition(
  (pos) => console.log(pos.coords.latitude, pos.coords.longitude),
  (err) => console.log("کاربر اجازه نداد:", err.message)
);
۲

JSON

JSON متنی است که آبجکت‌ها را برای ذخیره یا ارسال نشان می‌دهد. کلیدها و رشته‌ها حتماً با دابل‌کوتیشن‌اند و کامنت و ویرگول آخر مجاز نیست.

کد · قابل اجراjs
const user = { name: "Ali", skills: ["JS", "CSS"], active: true };
const text = JSON.stringify(user);       // آبجکت → متن
console.log(text);
const back = JSON.parse(text);           // متن → آبجکت
console.log(back.skills[0]);
try { JSON.parse("{name: 'Ali'}"); } catch (e) { console.log("JSON نامعتبر"); }
۳

LocalStorage

حافظه‌ی کوچک مرورگر برای ذخیره‌ی متن، که با بستن مرورگر پاک نمی‌شود. فقط رشته می‌پذیرد، پس برای آبجکت و آرایه باید از JSON استفاده کنی. این مثال را در فایل HTML خودت اجرا کن:

کدjs
const KEY = "todos";
const load = () => JSON.parse(localStorage.getItem(KEY) || "[]");
const save = (list) => localStorage.setItem(KEY, JSON.stringify(list));

const todos = load();
todos.push({ id: Date.now(), title: "یادگیری جاوااسکریپت", done: false });
save(todos);
console.log(load());

// localStorage.removeItem(KEY);   // حذف یک کلید
// localStorage.clear();           // پاک کردن همه
نکته‌ی امنیتی

هرگز رمز عبور یا توکن حساس را در LocalStorage نگذار. هر اسکریپتی در همان صفحه می‌تواند آن را بخواند. برای پروژه‌ی تودولیست و تنظیمات تم اشکالی ندارد.

تمرین‌ها

تمرین ۱

تم تیره/روشن را در LocalStorage ذخیره کن تا بعد از رفرش بماند

راهنمایی

هنگام کلیک، localStorage.setItem("theme", "dark") را بزن و هنگام لود صفحه، با getItem("theme") مقدار را بخوان و کلاس مناسب را به body بده.

تمرین ۲

آبجکتی را به JSON تبدیل و دوباره بازیابی کن

دیدن پاسخ
کد · قابل اجراjs
const data = { id: 1, tags: ["a", "b"] };
const copy = JSON.parse(JSON.stringify(data));
copy.tags.push("c");
console.log(data.tags, copy.tags);
روش تمرین

اول خودت حل کن، بعد پاسخ را ببین و با راه‌حل خودت مقایسه کن. چند راه درست برای یک مسئله وجود دارد.
