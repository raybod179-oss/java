DOM: انتخاب و تغییر المنت‌ها

مرورگر هر صفحه‌ی HTML را به یک درخت از آبجکت‌ها به نام DOM تبدیل می‌کند. جاوااسکریپت با همین درخت صفحه را می‌خواند و تغییر می‌دهد. در مثال‌های این فصل، دکمه‌ی «اجرای زنده» صفحه‌ی واقعی را زیر کد نشان می‌دهد.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. انتخاب المنت
  2. textContent و innerHTML
  3. Attribute و Class

۱

انتخاب المنت

querySelector اولین المنت مطابق انتخابگر CSS را می‌دهد و querySelectorAll همه را.

کد (HTML و JS) · قابل اجراhtml
<h2 id="title">سلام</h2>
<p class="txt">متن اول</p>
<p class="txt">متن دوم</p>
<button id="btn">تغییر بده</button>
<script>
const title = document.querySelector("#title");
const texts = document.querySelectorAll(".txt");
document.querySelector("#btn").addEventListener("click", () => {
  title.textContent = "عوض شد!";
  title.style.color = "tomato";
  texts.forEach((t) => (t.style.fontWeight = "bold"));
});
</script>
۲

textContent و innerHTML

textContent فقط متن را می‌گذارد. innerHTML کد HTML را هم تفسیر می‌کند.

کد (HTML و JS) · قابل اجراhtml
<div id="a"></div>
<div id="b"></div>
<script>
document.getElementById("a").textContent = "<b>متن ساده</b>";
document.getElementById("b").innerHTML = "<b>پررنگ</b> و <i>کج</i>";
</script>
امنیت

هرگز متنی را که کاربر تایپ کرده با innerHTML در صفحه نگذار. با تزریق کد (XSS) می‌شود از سایتت سوءاستفاده کرد. برای متن کاربر از textContent استفاده کن.

۳

Attribute و Class

کد (HTML و JS) · قابل اجراhtml
<a id="link" href="#">لینک من</a>
<p id="box">این کادر را روشن و خاموش کن</p>
<button id="t">Toggle</button>
<style>.on{background:#22d3ee;padding:6px;border-radius:6px}</style>
<script>
const link = document.getElementById("link");
link.setAttribute("href", "https://rayvo.vercel.app");
link.setAttribute("target", "_blank");
const box = document.getElementById("box");
document.getElementById("t").onclick = () => box.classList.toggle("on");
</script>

در classList این متدها را داری: add، remove، toggle، contains. تغییر کلاس تمیزتر از نوشتن style مستقیم است، چون ظاهر در CSS می‌ماند.

تمرین ۱

دکمه‌ای بساز که با هر کلیک رنگ پس‌زمینه‌ی صفحه را عوض کند

دیدن پاسخ
کد (HTML و JS) · قابل اجراhtml
<button id="b">رنگ جدید</button>
<script>
const colors = ["#fde68a", "#bbf7d0", "#bfdbfe"];
let i = 0;
document.getElementById("b").onclick = () => {
  document.body.style.background = colors[i++ % colors.length];
};
</script>
تمرین ۲

چالش: با یک دکمه، متن یک پاراگراف را بین «بیشتر بخوان» و «کمتر» عوض کن

دیدن پاسخ
کد (HTML و JS) · قابل اجراhtml
<p id="p" style="max-height:1.8em;overflow:hidden">این یک متن طولانی است که ابتدا فقط یک خط آن دیده می‌شود و با کلیک کامل باز می‌شود. این یک متن طولانی است که ابتدا فقط یک خط آن دیده می‌شود.</p>
<button id="b">بیشتر بخوان</button>
<script>
const p = document.getElementById("p"), b = document.getElementById("b");
b.onclick = () => {
  const open = p.style.maxHeight === "none";
  p.style.maxHeight = open ? "1.8em" : "none";
  b.textContent = open ? "بیشتر بخوان" : "کمتر";
};
</script>
