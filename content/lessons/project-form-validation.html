پروژه‌ی اعتبارسنجی فرم

اعتبارسنجی لحظه‌ای فرم با پیام خطای زیر هر فیلد: نام، ایمیل، موبایل ایرانی، رمز و تکرار رمز. قوانین را در یک آبجکت جمع می‌کنیم تا افزودن قانون جدید فقط یک خط باشد. این الگو در پروژه‌های واقعی بسیار مفید است.

<script>
const form = document.getElementById("form");
const go = document.getElementById("go");

// هر قانون: تابعی که در صورت خطا متن خطا و در صورت درست بودن "" برمی‌گرداند
const rules = {
  name:  (v) => (v.trim().split(/\s+/).length >= 2 ? "" : "نام و نام خانوادگی را کامل بنویس"),
  email: (v) => (/^[\w.+-]+@[\w-]+\.[\w.-]+$/.test(v) ? "" : "ایمیل معتبر نیست"),
  phone: (v) => (/^09\d{9}$/.test(v) ? "" : "موبایل باید با 09 شروع شود و ۱۱ رقم باشد"),
  pass:  (v) => (v.length >= 8 && /\d/.test(v) && /[a-zA-Z]/.test(v) ? "" : "حداقل ۸ کاراکتر با حرف و عدد"),
  pass2: (v) => (v === form.elements.pass.value && v !== "" ? "" : "تکرار رمز یکسان نیست"),
};
const touched = new Set();                              // فقط فیلدهایی که کاربر لمس کرده

function check(name, showError = true) {
  const input = form.elements[name];
  const error = rules[name](input.value);
  if (showError) {
    const box = input.closest(".f");
    box.classList.toggle("bad", !!error);
    box.classList.toggle("good", !error);
    box.querySelector(".err").textContent = error;
  }
  return !error;
}
function refresh() {
  go.disabled = !Object.keys(rules).every((n) => check(n, touched.has(n)));
}

form.addEventListener("input", (e) => {
  touched.add(e.target.name);
  if (e.target.name === "pass") touched.has("pass2") && check("pass2");
  refresh();
});
form.addEventListener("submit", (e) => {
  e.preventDefault();
  if (Object.keys(rules).every((n) => check(n))) document.getElementById("ok").hidden = false;
});
</script>

قدم ۱: قانون‌ها در یک آبجکت

هر قانون یک تابع کوچک است که متن خطا یا رشته‌ی خالی برمی‌گرداند. اضافه کردن قانون برای فیلد جدید یعنی فقط یک خط. اینجا Regex که در درس ۱۵ دیدی کاربرد واقعی دارد، مثلاً /^09\d{9}$/ یعنی «با ۰۹ شروع شود و ۹ رقم بعدش بیاید».

JavaScriptjs
const rules = {
  phone: (v) => (/^09\d{9}$/.test(v) ? "" : "موبایل معتبر نیست"),
};

قدم ۲: نمایش خطا فقط بعد از لمس

اگر همان لحظه‌ی باز شدن فرم همه‌ی فیلدها قرمز شوند، تجربه‌ی بدی است. پس مجموعه‌ی touched نگه می‌داریم و خطا را فقط برای فیلدهایی نشان می‌دهیم که کاربر در آن‌ها تایپ کرده است. با این حال دکمه تا وقتی همه‌ی فیلدها درست نباشند غیرفعال می‌ماند.

JavaScriptjs
go.disabled = !Object.keys(rules).every((n) => check(n, touched.has(n)));
۵

قدم ۳: تکرار رمز

قانون pass2 به مقدار فیلد دیگر وابسته است. برای همین وقتی رمز اصلی عوض می‌شود، اگر تکرار رمز قبلاً لمس شده بود، دوباره آن را بررسی می‌کنیم تا خطای قدیمی نماند.

JavaScriptjs
if (e.target.name === "pass") touched.has("pass2") && check("pass2");

مفاهیمی که در این پروژه استفاده شد

این پروژه بخش‌هایی از درس‌های قبل را به هم وصل می‌کند. اگر جایی نفهمیدی، همان درس را دوباره بخوان:

  • Regex (درس ۱۵)
  • Set و Object.keys (درس‌های ۱۴ و ۱۱)
  • every (درس ۱۲)
  • تابع به‌عنوان مقدار و Arrow Function (درس ۷)
  • Event Delegation روی فرم (درس ۲۵)

اشتباه‌های رایج

Regex بسیار پیچیده برای ایمیل

هیچ Regex ساده‌ای همه‌ی ایمیل‌های معتبر را پوشش نمی‌دهد. الگوی ساده بنویس و ایمیل واقعی را با ارسال لینک تأیید بسنج.

اعتماد به اعتبارسنجی کلاینت

کاربر می‌تواند جاوااسکریپت را دور بزند. سرور همیشه باید دوباره اعتبارسنجی کند.
