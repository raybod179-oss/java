پروژه‌ی فروشگاه با سبد خرید

یک فروشگاه کوچک با سبد خرید کامل: افزودن محصول، تغییر تعداد، حذف، جمع کل، شمارنده‌ی روی آیکون سبد و ماندن سبد بعد از رفرش. بزرگ‌ترین درس این پروژه جدا کردن «داده» (سبد) از «نمایش» است و همین مفهوم پایه‌ی هر فروشگاه اینترنتی است.

const PRODUCTS = [
  { id: 1, name: "هدفون", emoji: "🎧", price: 950000 },
  { id: 2, name: "کتاب", emoji: "📘", price: 240000 },
  { id: 3, name: "ساعت", emoji: "⌚", price: 1400000 },
  { id: 4, name: "کوله‌پشتی", emoji: "🎒", price: 780000 },
  { id: 5, name: "لیوان", emoji: "☕", price: 90000 },
  { id: 6, name: "ماوس", emoji: "🖱️", price: 520000 },
];
const KEY = "cart-v1";
const money = (n) => n.toLocaleString("fa-IR") + " تومان";

// سبد: { شناسه: تعداد }
let cart = (() => { try { return JSON.parse(localStorage.getItem(KEY)) || {}; } catch (e) { return {}; } })();
const save = () => { try { localStorage.setItem(KEY, JSON.stringify(cart)); } catch (e) {} };

const grid = document.getElementById("grid");
PRODUCTS.forEach((p) => {
  const d = document.createElement("div");
  d.className = "prod";
  d.innerHTML = "<div class='em'></div><b></b><small></small><button>افزودن به سبد</button>";
  d.querySelector(".em").textContent = p.emoji;
  d.querySelector("b").textContent = p.name;
  d.querySelector("small").textContent = money(p.price);
  d.querySelector("button").addEventListener("click", () => change(p.id, 1));
  grid.append(d);
});

function change(id, delta) {
  cart[id] = (cart[id] || 0) + delta;
  if (cart[id] <= 0) delete cart[id];
  save();
  render();
}

function render() {
  const rows = document.getElementById("rows");
  rows.innerHTML = "";
  let total = 0, count = 0;
  Object.entries(cart).forEach(([id, qty]) => {
    const p = PRODUCTS.find((x) => x.id === Number(id));
    total += p.price * qty; count += qty;
    const r = document.createElement("div");
    r.className = "row";
    r.innerHTML = "<span></span><button data-d='-1'>−</button><b></b><button data-d='1'>+</button>";
    r.querySelector("span").textContent = p.emoji + " " + p.name;
    r.querySelector("b").textContent = qty.toLocaleString("fa-IR");
    r.querySelectorAll("button").forEach((b) => b.addEventListener("click", () => change(p.id, Number(b.dataset.d))));
    rows.append(r);
  });
  if (!count) rows.innerHTML = "<p class='muted'>سبد خالی است</p>";
  document.getElementById("total").textContent = money(total);
  document.getElementById("badge").textContent = count.toLocaleString("fa-IR");
}

const panel = document.getElementById("cart");
document.getElementById("open").addEventListener("click", () => panel.classList.add("open"));
document.getElementById("close").addEventListener("click", () => panel.classList.remove("open"));
document.getElementById("pay").addEventListener("click", () => {

  if (Object.keys(cart).length) { cart = {}; save(); render(); }
});
render();

قدم ۱: سبد فقط یک آبجکت است

سبد را به‌صورت { شناسه: تعداد } نگه می‌داریم، مثلاً { 1: 2, 4: 1 }. نه HTML و نه نام محصول؛ فقط شناسه و تعداد. قیمت و نام را هر بار از آرایه‌ی PRODUCTS می‌گیریم (یک منبع حقیقت) تا اگر قیمت عوض شد، سبد قدیمی قیمت اشتباه نگه ندارد.

JavaScriptjs
let cart = { 1: 2, 4: 1 };   // دو هدفون و یک کوله
۴

قدم ۲: یک تابع برای همه‌ی تغییرات

افزودن، کم کردن و حذف همه از change(id, delta) می‌گذرد: تعداد را تغییر می‌دهد، اگر صفر یا کمتر شد ورودی را حذف می‌کند، ذخیره می‌کند و دوباره می‌سازد. تابع render همیشه از صفر لیست و جمع کل را حساب می‌کند، پس هیچ‌وقت با داده‌ی صفحه ناهماهنگ نمی‌شود.

JavaScriptjs
function change(id, delta) {
  cart[id] = (cart[id] || 0) + delta;
  if (cart[id] <= 0) delete cart[id];
  save(); render();
}
۵

قدم ۳: جمع کل با Object.entries

Object.entries(cart) آبجکت را به آرایه‌ی [شناسه، تعداد] تبدیل می‌کند و می‌توانیم با حلقه و find محصول را پیدا کنیم و price × qty را جمع بزنیم. سبد در localStorage ذخیره می‌شود، پس بعد از رفرش هم می‌ماند. پنل سبد فقط یک کلاس open و transform دارد.

JavaScriptjs
Object.entries(cart).forEach(([id, qty]) => {
  const p = PRODUCTS.find((x) => x.id === Number(id));
  total += p.price * qty;
});

مفاهیمی که در این پروژه استفاده شد

این پروژه بخش‌هایی از درس‌های قبل را به هم وصل می‌کند. اگر جایی نفهمیدی، همان درس را دوباره بخوان:

  • آبجکت، delete و Object.entries (درس‌های ۳ و ۱۴)
  • find و forEach (درس‌های ۱۱ و ۱۲)
  • localStorage و JSON (درس ۲۷)
  • تابع، پارامتر پیش‌فرض و || (درس‌های ۴ و ۷)
  • جداسازی داده از نمایش (درس ۲۷)

اشتباه‌های رایج

ذخیره‌ی قیمت داخل سبد

اگر قیمت را در سبد کپی کنی و بعداً قیمت عوض شود، مشتری قیمت قدیمی را می‌بیند. فقط شناسه و تعداد بگذار.

اعتماد به قیمت سمت کاربر

در فروشگاه واقعی قیمت نهایی را حتماً سرور حساب می‌کند؛ هر چیزی در مرورگر قابل دست‌کاری است.
