Promise

Promise یعنی «قولی برای یک نتیجه در آینده». سه وضعیت دارد: pending (در انتظار)، fulfilled (موفق) و rejected (ناموفق). وقتی یک بار تعیین تکلیف شد، دیگر عوض نمی‌شود.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. ساختن Promise
  2. اجرای چند Promise با هم
  3. تمرین‌ها
۱

ساختن Promise

کد · قابل اجراjs
const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
const getUser = (id) => new Promise((resolve, reject) => {
  setTimeout(() => {
    if (id > 0) resolve({ id, name: "Ali" });
    else reject(new Error("شناسه نامعتبر"));
  }, 300);
});

getUser(1)
  .then((user) => { console.log("کاربر:", user.name); return user.id; })
  .then((id) => console.log("شناسه:", id))
  .catch((err) => console.log("خطا:", err.message))
  .finally(() => console.log("پایان"));

then نتیجه‌ی موفق را می‌گیرد و می‌توان آن‌ها را زنجیر کرد، چون هر then یک Promise جدید برمی‌گرداند. یک catch در انتهای زنجیره، خطای هر مرحله را می‌گیرد. finally در هر دو حالت اجرا می‌شود و برای خاموش کردن loading مناسب است.

کد · قابل اجراjs
const getUser = (id) => new Promise((resolve, reject) => {
  setTimeout(() => (id > 0 ? resolve({ id }) : reject(new Error("شناسه نامعتبر"))), 200);
});
getUser(-1)
  .then((u) => console.log("این اجرا نمی‌شود", u))
  .catch((e) => console.log("خطا:", e.message));
۲

اجرای چند Promise با هم

کد · قابل اجراjs
const delay = (v, ms) => new Promise((r) => setTimeout(() => r(v), ms));

Promise.all([delay("الف", 300), delay("ب", 100)])
  .then((r) => console.log("all:", r));            // منتظر همه

Promise.race([delay("کند", 300), delay("سریع", 100)])
  .then((r) => console.log("race:", r));           // اولین نتیجه

Promise.allSettled([delay("ok", 50), Promise.reject(new Error("fail"))])
  .then((r) => console.log(r.map((x) => x.status)));
تفاوت مهم

اگر یکی از Promiseهای Promise.all رد شود، کل نتیجه رد می‌شود. وقتی می‌خواهی حتی با شکست بعضی‌ها بقیه‌ی نتیجه‌ها را داشته باشی، از allSettled استفاده کن.

تمرین‌ها

تمرین ۱

تابع wait(ms) بساز که Promise برگرداند و با آن بعد از ۵۰۰ میلی‌ثانیه چیزی چاپ کن

دیدن پاسخ
کد · قابل اجراjs
const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
wait(500).then(() => console.log("۵۰۰ میلی‌ثانیه گذشت"));
تمرین ۲

چالش: دو Promise موفق و یک ناموفق بساز و با allSettled فقط موفق‌ها را چاپ کن

دیدن پاسخ
کد · قابل اجراjs
const ok = (v) => Promise.resolve(v);
Promise.allSettled([ok(1), Promise.reject("x"), ok(3)]).then((rs) => {
  const good = rs.filter((r) => r.status === "fulfilled").map((r) => r.value);
  console.log(good);
});
