<script>
const slider = document.getElementById("slider");
const track = document.getElementById("track");
const dotsBox = document.getElementById("dots");
const slides = track.children;
let index = 0;
let timer = null;

// ساخت نقطه‌ها از روی تعداد اسلایدها
[...slides].forEach((_, i) => {
  const dot = document.createElement("button");
  dot.className = "dot";
  dot.setAttribute("aria-label", "اسلاید " + (i + 1));
  dot.addEventListener("click", () => goTo(i));
  dotsBox.append(dot);
});

function goTo(i) {
  index = (i + slides.length) % slides.length;       // چرخش بی‌نهایت
  track.style.transform = "translateX(" + index * 100 + "%)";   // در صفحه‌ی راست‌چین مثبت است
  [...dotsBox.children].forEach((d, n) => d.classList.toggle("active", n === index));
}
const next = () => goTo(index + 1);
const prev = () => goTo(index - 1);

function play() { stop(); timer = setInterval(next, 4000); }
function stop() { clearInterval(timer); }

document.getElementById("next").addEventListener("click", next);
document.getElementById("prev").addEventListener("click", prev);
slider.addEventListener("mouseenter", stop);          // موس روی اسلایدر: توقف
slider.addEventListener("mouseleave", play);
document.addEventListener("keydown", (e) => {
  if (e.key === "ArrowLeft") next();                  // راست‌چین: چپ یعنی بعدی
  if (e.key === "ArrowRight") prev();
});

// کشیدن با انگشت
let startX = 0;
slider.addEventListener("touchstart", (e) => { startX = e.touches[0].clientX; }, { passive: true });
slider.addEventListener("touchend", (e) => {
  const dx = e.changedTouches[0].clientX - startX;
  if (Math.abs(dx) > 40) (dx < 0 ? next : prev)();
});

goTo(0);
play();
</script>

پوشه‌ی پروژه و اجرا

برای ساخت روی کامپیوتر خودت یک پوشه با این ساختار بساز:

ساختار پوشهtxt
slider/
├── index.html   ← ساختار صفحه (HTML)
├── style.css    ← ظاهر (CSS)
└── script.js    ← منطق (JavaScript)
چطور اجرا کنم؟

فایل index.html را در مرورگر باز کن، یا در VS Code با افزونه‌ی Live Server روی آن راست‌کلیک و «Open with Live Server» را بزن تا با هر ذخیره، صفحه خودکار تازه شود.

قدم ۱: ردیف اسلایدها

همه‌ی اسلایدها کنار هم در یک track افقی هستند و هر کدام ۱۰۰٪ عرض دارند (flex: 0 0 100%). قاب بیرونی با overflow:hidden فقط یکی را نشان می‌دهد. برای عوض کردن اسلاید، کل track را با translateX می‌لغزانیم. چون صفحه راست‌چین است، جهت لغزش مثبت است.

CSScss
.viewport { overflow: hidden; }
.track { display: flex; transition: transform .45s ease; }
.slide { flex: 0 0 100%; }

قدم ۲: یک متغیر، همه‌ی منطق

تنها state برنامه index است. تابع goTo آن را با باقیمانده (%) به محدوده‌ی درست برمی‌گرداند؛ بنابراین از آخرین اسلاید به اولی می‌رود و برعکس. همین تابع هم از دکمه‌ها، هم از نقطه‌ها، هم از کیبورد و هم از پخش خودکار صدا زده می‌شود.

JavaScriptjs
function goTo(i) {
  index = (i + slides.length) % slides.length;
  track.style.transform = "translateX(" + index * 100 + "%)";
}

قدم ۳: پخش خودکار و لمس

با setInterval هر ۴ ثانیه یک اسلاید جلو می‌رویم و وقتی موس روی اسلایدر است clearInterval می‌کنیم تا کاربر بتواند بخواند. برای موبایل، فاصله‌ی افقی بین touchstart و touchend را حساب می‌کنیم؛ اگر بیشتر از ۴۰ پیکسل بود، یعنی کاربر کشیده است.

JavaScriptjs
slider.addEventListener("mouseenter", stop);
slider.addEventListener("mouseleave", play);

این پروژه بخش‌هایی از درس‌های قبل را به هم وصل می‌کند. اگر جایی نفهمیدی، همان درس را دوباره بخوان:

اشتباه‌های رایج

عدد منفی در باقیمانده

در جاوااسکریپت -1 % 3 برابر -1 است، نه ۲. برای همین قبل از % طول آرایه را اضافه می‌کنیم.

تایمر چندباره

اگر قبل از setInterval تایمر قبلی را پاک نکنی، با هر mouseleave یک تایمر اضافه می‌شود و اسلایدر دیوانه‌وار می‌چرخد.
