Clipboard.js: کپی با یک کلیک

دکمه‌ی «کپی کد» یا «کپی لینک» را در هر سایت دیده‌ای. کتابخانه‌ی Clipboard.js این کار را بدون دردسر و روی مرورگرهای مختلف انجام می‌دهد. با صفت‌های data- کار می‌کند و تقریباً هیچ جاوااسکریپتی نمی‌خواهد.

۱

این کتابخانه چه مشکلی را حل می‌کند؟

کپی کردن متن با جاوااسکریپت تاریخچه‌ی پیچیده‌ای دارد: روش قدیمی document.execCommand("copy") و روش جدید navigator.clipboard.writeText() که فقط در صفحه‌ی امن (HTTPS) و با اجازه‌ی کاربر کار می‌کند. Clipboard.js روش‌ها را پنهان می‌کند و فقط یک رابط ساده می‌دهد.

۲

نصب

در این صفحه برای اینکه نمونه‌ها بدون اینترنت و بدون وابستگی به CDN اجرا شوند، نسخه‌ی کتابخانه از خود سایت بارگیری می‌شود. در پروژه‌ی خودت یکی از این دو روش را به کار ببر:

روش ۱: CDN (فقط چند تگ در HTML)html
<script src="https://cdn.jsdelivr.net/npm/clipboard@2.0.11/dist/clipboard.min.js"></script>
روش ۲: npm (برای پروژه‌هایی که با Vite یا Webpack ساخته می‌شوند)txt
npm install clipboard
۳

استفاده‌ی پایه

به هر دکمه یکی از دو صفت را بده: data-clipboard-text (متن ثابت) یا data-clipboard-target (انتخابگر المنتی که متنش کپی شود). بعد یک‌بار new ClipboardJS(".btn") بنویس.

کد (HTML و JS) · قابل اجراhtml
<input id="code" value="npm install clipboard" readonly style="padding:8px;width:220px;direction:ltr">
<button class="btn" data-clipboard-target="#code">کپی از فیلد</button>
<button class="btn" data-clipboard-text="این متن ثابت است">کپی متن ثابت</button>
<p id="out"></p>

<script src="/assets/vendor/clipboard.min.js"></script>
<script>
const clip = new ClipboardJS(".btn");
clip.on("success", (e) => {
  document.getElementById("out").textContent = "کپی شد ✓ : " + e.text;
  e.clearSelection();
});
clip.on("error", () => {
  document.getElementById("out").textContent = "مرورگر اجازه نداد؛ دستی کپی کن.";
});
</script>
نکته درباره‌ی این پیش‌نمایش

اگر در این پیش‌نمایش پیام «مرورگر اجازه نداد» دیدی، بدان که کادر ایمن صفحه‌ی درس دسترسی به کلیپ‌بورد را محدود کرده. در پروژه‌ی خودت (فایل HTML روی سرور خودت) بدون مشکل کار می‌کند.

۴

رویدادها و روش مدرن بدون کتابخانه

رویداد success وقتی کپی موفق بود و error وقتی نبود اجرا می‌شود. در پروژه‌های جدید، اگر فقط یک دکمه‌ی کپی داری، خود مرورگر هم کافی است:

روش مدرن (بدون کتابخانه)js
button.addEventListener("click", async () => {
  try {
    await navigator.clipboard.writeText("متنی که می‌خواهی کپی شود");
    button.textContent = "کپی شد ✓";
  } catch (err) {
    button.textContent = "اجازه داده نشد";
  }
});
بدان

Clipboard.js وقتی ارزش دارد که دکمه‌های زیاد داری (مثلاً هر بلوک کد یک دکمه) یا باید مرورگرهای قدیمی را هم پشتیبانی کنی.
