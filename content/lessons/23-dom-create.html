ساخت و افزودن

اول با createElement المنت را در حافظه می‌سازی، بعد با append یا prepend در صفحه می‌گذاری.

کد (HTML و JS) · قابل اجراhtml
<ul id="list"></ul>
<button id="add">افزودن آیتم</button>
<script>
const list = document.getElementById("list");
let n = 0;
document.getElementById("add").onclick = () => {
  const li = document.createElement("li");
  li.textContent = "آیتم " + (++n);
  list.append(li);
};
</script>

حذف المنت با کلیک

کد (HTML و JS) · قابل اجراhtml
<ul id="list"><li>روی من کلیک کن</li><li>من هم</li><li>من هم</li></ul>
<script>
document.querySelectorAll("#list li").forEach((li) => {
  li.style.cursor = "pointer";
  li.onclick = () => li.remove();
});
</script>

جایگاه المنت

چهار روش درج نسبت به یک المنت: before (قبل)، after (بعد)، prepend (اول فرزندان)، append (آخر فرزندان). با insertAdjacentHTML هم می‌توانی HTML خام را در این چهار جایگاه بگذاری.

کد (HTML و JS) · قابل اجراhtml
<div id="box" style="border:1px solid #888;padding:8px">
  <b id="mid">وسط</b>
</div>
<script>
const mid = document.getElementById("mid");
const mk = (t) => Object.assign(document.createElement("span"), { textContent: " " + t + " " });
mid.before(mk("قبل"));
mid.after(mk("بعد"));
document.getElementById("box").prepend(mk("اول"));
document.getElementById("box").append(mk("آخر"));
</script>

پیمایش DOM

کد (HTML و JS) · قابل اجراhtml
<ul id="menu"><li>الف</li><li id="two">ب</li><li>ج</li></ul>
<p id="out"></p>
<script>
const two = document.getElementById("two");
document.getElementById("out").textContent = [
  "قبلی: " + two.previousElementSibling.textContent,
  "بعدی: " + two.nextElementSibling.textContent,
  "پدر: " + two.parentElement.id,
  "تعداد فرزندان پدر: " + two.parentElement.children.length,
].join(" | ");
</script>

تمرین‌ها

تمرین ۱

فیلد متنی و دکمه بساز که هر متن را به لیست اضافه کند و ورودی را خالی کند

دیدن پاسخ
کد (HTML و JS) · قابل اجراhtml
<input id="i" placeholder="کار جدید">
<button id="a">افزودن</button>
<ul id="l"></ul>
<script>
const i = document.getElementById("i"), l = document.getElementById("l");
document.getElementById("a").onclick = () => {
  const v = i.value.trim();
  if (!v) return;
  const li = document.createElement("li");
  li.textContent = v;
  l.append(li);
  i.value = "";
};
</script>
