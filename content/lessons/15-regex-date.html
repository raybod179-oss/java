Regex: الگوی جستجو در متن

بین دو اسلش می‌نویسیم. \d رقم، \w حرف یا رقم، + یک یا بیشتر، ^ و $ ابتدا و انتهای متن.

کد · قابل اجراjs
const phone = /^09\d{9}$/;
console.log(phone.test("09123456789"));   // true
console.log(phone.test("0912"));          // false
console.log("a1b22c333".match(/\d+/g));   // [ "1", "22", "333" ]
console.log("2026-11-04".replace(/-/g, "/"));
const email = /^[\w.-]+@[\w.-]+\.\w+$/;
console.log(email.test("me@rayvo.dev"));
نکته

فلگ g یعنی همه‌ی موردها، نه فقط اولی. regex برای اعتبارسنجی اولیه خوب است، اما اعتبارسنجی نهایی همیشه باید در سرور هم انجام شود.

Date

کد · قابل اجراjs
const d = new Date(2026, 10, 4, 15, 30);   // ماه از صفر: 10 یعنی نوامبر
console.log(d.getFullYear(), d.getMonth() + 1, d.getDate());
console.log(d.getDay());                  // 0 یکشنبه ... 6 شنبه
const next = new Date(d);
next.setDate(next.getDate() + 30);        // 30 روز بعد
console.log(next.toISOString().slice(0, 10));
const diff = new Date("2026-12-01") - new Date("2026-11-01");
console.log(diff / (1000 * 60 * 60 * 24), "روز");
کد · قابل اجراjs
console.log(new Date("2026-11-04T10:00:00Z").toLocaleDateString("fa-IR"));
console.log(Date.now() > 0);
دام معروف

شماره‌ی ماه در Date از صفر شروع می‌شود، ولی روز از یک.
