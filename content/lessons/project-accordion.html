نتیجه‌ی نهایی و کد کامل

روی «اجرای زنده» بزن و با پروژه کار کن. کد کامل (CSS و HTML و JavaScript) همین‌جا هست؛ در بخش‌های بعد قدم‌به‌قدم توضیح داده شده. بهتر است اول خودت بسازی و فقط وقتی گیر کردی نگاه کنی.

<script>
const items = [...document.querySelectorAll(".acc-item")];

function setOpen(item, open) {
  const button = item.querySelector(".acc-q");
  const panel = item.querySelector(".acc-a");
  button.setAttribute("aria-expanded", String(open));
  item.classList.toggle("open", open);
  panel.style.maxHeight = open ? panel.scrollHeight + "px" : "0px";
}

items.forEach((item) => {
  item.querySelector(".acc-q").addEventListener("click", () => {
    const wasOpen = item.classList.contains("open");
    items.forEach((other) => setOpen(other, false));   // همه را ببند
    if (!wasOpen) setOpen(item, true);                  // اگر بسته بود، این یکی را باز کن
  });
});

setOpen(items[0], true);                                // در شروع، اولی باز باشد
</script>

پوشه‌ی پروژه و اجرا

برای ساخت روی کامپیوتر خودت یک پوشه با این ساختار بساز:

ساختار پوشهtxt
accordion/
├── index.html   ← ساختار صفحه (HTML)
├── style.css    ← ظاهر (CSS)
└── script.js    ← منطق (JavaScript)
چطور اجرا کنم؟

فایل index.html را در مرورگر باز کن، یا در VS Code با افزونه‌ی Live Server روی آن راست‌کلیک و «Open with Live Server» را بزن تا با هر ذخیره، صفحه خودکار تازه شود.

قدم ۱: HTML

هر آیتم یک دکمه‌ی سؤال و یک جعبه‌ی پاسخ دارد. استفاده از button (نه div) مهم است: خودش با کیبورد فوکوس می‌گیرد و با Enter کار می‌کند. صفت aria-expanded وضعیت باز یا بسته را به فناوری‌های کمکی می‌گوید.

HTMLhtml
<button class="acc-q" aria-expanded="false">دوره ویدیویی است؟</button>
<div class="acc-a"><p>نه…</p></div>

قدم ۲: انیمیشن ارتفاع

مرورگر نمی‌تواند از height:0 به height:auto انیمیت کند. ترفند این است که با max-height کار کنیم: بسته = ۰، باز = ارتفاع واقعی محتوا که با scrollHeight از جاوااسکریپت می‌گیریم. علامت + هم با rotate(45deg) به × تبدیل می‌شود.

CSScss
.acc-a { max-height: 0; overflow: hidden; transition: max-height .3s ease; }
۵

قدم ۳: فقط یکی باز

با کلیک روی یک آیتم، اول همه را می‌بندیم و بعد اگر آن آیتم قبلاً بسته بود، بازش می‌کنیم. اگر باز بود، همان بسته می‌ماند. این سه خط منطق، رفتار «یک‌باز» را می‌سازند.

JavaScriptjs
const wasOpen = item.classList.contains("open");
items.forEach((other) => setOpen(other, false));
if (!wasOpen) setOpen(item, true);

مفاهیمی که در این پروژه استفاده شد

این پروژه بخش‌هایی از درس‌های قبل را به هم وصل می‌کند. اگر جایی نفهمیدی، همان درس را دوباره بخوان:

  • querySelectorAll و تبدیل به آرایه با Spread (درس‌های ۱۳ و ۲۲)
  • forEach (درس ۱۲)
  • classList.toggle (درس ۲۲)
  • شرط و عملگر سه‌تایی (درس ۵)

اشتباه‌های رایج

استفاده از div به‌جای button

با div باید خودت tabindex و کیبورد را بسازی؛ button همه را رایگان دارد.

اگر متن پاسخ بلندتر شد بریده می‌شود. به همین دلیل از scrollHeight استفاده می‌کنیم.
