Swiper: اسلایدر لمسی حرفه‌ای

Swiper محبوب‌ترین کتابخانه‌ی اسلایدر است: لمسی، ریسپانسیو، با صفحه‌بندی، دکمه‌ها، پخش خودکار و افکت‌های مختلف. اسلایدر نظرات و تصاویر را خودت دستی ساختی؛ حالا می‌بینی همان‌ها با Swiper چقدر کوتاه می‌شوند.

نصب

در این صفحه برای اینکه نمونه‌ها بدون اینترنت و بدون وابستگی به CDN اجرا شوند، نسخه‌ی کتابخانه از خود سایت بارگیری می‌شود. در پروژه‌ی خودت یکی از این دو روش را به کار ببر:

روش ۱: CDN (فقط چند تگ در HTML)html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/swiper@11.2.10/swiper-bundle.min.css">
<script src="https://cdn.jsdelivr.net/npm/swiper@11.2.10/swiper-bundle.min.js"></script>
روش ۲: npm (برای پروژه‌هایی که با Vite یا Webpack ساخته می‌شوند)txt
npm install swiper@11
۲

ساختار و استفاده‌ی پایه

ساختار HTML سه لایه است: .swiper ← .swiper-wrapper ← چند .swiper-slide. برای راست‌چین بودن، صفت dir="rtl" را روی .swiper بگذار.

کد (HTML و JS) · قابل اجراhtml
<link rel="stylesheet" href="/assets/vendor/swiper-bundle.min.css">
<style>
  .swiper { width: 100%; height: 190px; }
  .swiper-slide { display: grid; place-items: center; font-size: 24px; color: #1a1204; border-radius: 14px; }
</style>

<div class="swiper" dir="rtl">
  <div class="swiper-wrapper">
    <div class="swiper-slide" style="background:#fbbf24">اسلاید ۱</div>
    <div class="swiper-slide" style="background:#fb923c">اسلاید ۲</div>
    <div class="swiper-slide" style="background:#4ade80">اسلاید ۳</div>
    <div class="swiper-slide" style="background:#60a5fa">اسلاید ۴</div>
  </div>
  <div class="swiper-pagination"></div>
  <div class="swiper-button-prev"></div>
  <div class="swiper-button-next"></div>
</div>

<script src="/assets/vendor/swiper-bundle.min.js"></script>
<script>
new Swiper(".swiper", {
  loop: true,
  spaceBetween: 12,
  autoplay: { delay: 2500, disableOnInteraction: false },
  pagination: { el: ".swiper-pagination", clickable: true },
  navigation: { nextEl: ".swiper-button-next", prevEl: ".swiper-button-prev" },
  breakpoints: { 600: { slidesPerView: 2 } },     // از ۶۰۰ پیکسل به بالا، ۲ اسلاید
});
</script>
۳

گزینه‌های مهم

  • slidesPerView و spaceBetween: تعداد اسلاید در دید و فاصله
  • loop: چرخش بی‌پایان
  • autoplay: { delay, disableOnInteraction }
  • pagination و navigation: نقطه‌ها و فلش‌ها
  • breakpoints: تنظیم متفاوت برای عرض‌های مختلف (ریسپانسیو)
  • effect: "fade"، "cube"، "coverflow" (برخی افکت‌ها ماژول جدا لازم دارند؛ نسخه‌ی bundle همه را دارد)
رویدادها و کنترلjs
const swiper = new Swiper(".swiper", { slidesPerView: 1 });
swiper.on("slideChange", () => console.log("اسلاید فعال:", swiper.realIndex));
swiper.slideTo(2);      // رفتن به اسلاید سوم
swiper.autoplay.stop(); // توقف پخش خودکار
چرا اول دستی ساختیم؟

پروژه‌ی «اسلایدر نظرات» را که ~۴۰ خط جاوااسکریپت بود با Swiper حدود ۱۰ خط می‌نویسی. ولی دانستن اینکه زیر کار چه می‌گذرد (index و translateX) همان چیزی است که تو را از کسی که فقط کتابخانه صدا می‌زند جدا می‌کند.

تمرین‌ها

تمرین ۱

اسلایدر نظرات دانشجوها را با Swiper بازنویسی کن (۳ اسلاید، نقطه‌ها و پخش خودکار).

راهنمایی

همان ساختار .swiper را کپی کن و فقط pagination و autoplay را بده.

تمرین ۲

با breakpoints در موبایل ۱ اسلاید، در تبلت ۲ و در دسکتاپ ۳ اسلاید نشان بده.

راهنمایی

کلیدها عرض صفحه و مقدارها { slidesPerView } هستند.
