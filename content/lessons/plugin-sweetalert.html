SweetAlert2: پیام‌های زیبا

alert() و confirm() مرورگر زشت‌اند، قابل شخصی‌سازی نیستند و صفحه را قفل می‌کنند. SweetAlert2 پنجره‌های پیام، تأیید و اعلان (toast) زیبا و قابل تنظیم می‌دهد و بر پایه‌ی Promise کار می‌کند؛ یعنی دقیقاً همان async/await که می‌شناسی.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. نصب
  2. سه حالت اصلی
  3. گزینه‌های پرکاربرد
  4. تمرین‌ها
۱

نصب

در این صفحه برای اینکه نمونه‌ها بدون اینترنت و بدون وابستگی به CDN اجرا شوند، نسخه‌ی کتابخانه از خود سایت بارگیری می‌شود. در پروژه‌ی خودت یکی از این دو روش را به کار ببر:

روش ۱: CDN (فقط چند تگ در HTML)html
<script src="https://cdn.jsdelivr.net/npm/sweetalert2@11"></script>
روش ۲: npm (برای پروژه‌هایی که با Vite یا Webpack ساخته می‌شوند)txt
npm install sweetalert2
یادآوری

نسخه‌ی all این کتابخانه CSS را هم داخل خودش دارد؛ تگ جداگانه‌ی استایل لازم نیست.

۲

سه حالت اصلی

همه‌ی کارها با Swal.fire({...}) انجام می‌شود. نتیجه یک Promise است که وقتی کاربر دکمه‌ای زد، یک آبجکت می‌دهد: isConfirmed، isDenied یا isDismissed.

کد (HTML و JS) · قابل اجراhtml
<button id="a">پیام ساده</button>
<button id="b">تأیید حذف</button>
<button id="c">اعلان (Toast)</button>

<script src="/assets/vendor/sweetalert2.all.min.js"></script>
<script>
document.getElementById("a").onclick = () =>
  Swal.fire({ title: "ثبت شد!", text: "اطلاعات ذخیره شد.", icon: "success", confirmButtonText: "باشه" });

document.getElementById("b").onclick = async () => {
  const result = await Swal.fire({
    title: "مطمئنی؟", text: "این کار برگشت‌ناپذیر است.", icon: "warning",
    showCancelButton: true, confirmButtonText: "بله، حذف کن", cancelButtonText: "انصراف",
  });
  if (result.isConfirmed) Swal.fire({ title: "حذف شد", icon: "success", timer: 1200, showConfirmButton: false });
};

document.getElementById("c").onclick = () =>
  Swal.fire({ toast: true, position: "top-end", icon: "info", title: "یک اعلان کوچک", showConfirmButton: false, timer: 2000 });
</script>
۳

گزینه‌های پرکاربرد

  • icon: success، error، warning، info، question
  • timer: بستن خودکار بعد از چند میلی‌ثانیه
  • input: گرفتن ورودی از کاربر ("text"، "email"، "select"، ...)
  • html: محتوای HTML دلخواه (فقط محتوای مطمئن!)
  • didOpen و willClose: تابع‌هایی برای لحظه‌ی باز و بسته شدن
گرفتن ورودی از کاربرjs
const { value: name } = await Swal.fire({
  title: "اسمت چیه؟",
  input: "text",
  inputPlaceholder: "نام",
  showCancelButton: true,
  inputValidator: (v) => (!v ? "نام را وارد کن" : null),
});
if (name) Swal.fire("سلام " + name + " 👋");
مراقب باش

گزینه‌ی html را هرگز با متنی که کاربر نوشته پر نکن؛ مثل innerHTML راه تزریق کد (XSS) می‌شود. متن کاربر را با text یا textContent نشان بده.

تمرین‌ها

تمرین ۱

در پروژه‌ی تودولیست، قبل از حذف یک کار با SweetAlert2 تأیید بگیر.

راهنمایی

داخل شنونده‌ی حذف، await Swal.fire({ showCancelButton: true, ... }) بزن و فقط وقتی isConfirmed بود حذف کن.

تمرین ۲

بعد از ارسال موفق فرم تماس (پروژه‌ی سایت تک‌صفحه‌ای) یک toast موفقیت نشان بده.

راهنمایی

گزینه‌های toast: true و timer.
