سطح ۱ · درس ۶

حلقه‌ها

هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. for
  2. while و do...while
  3. for...of و for...in
  4. break و continue
  5. تمرین‌ها
۱

for

سه بخش دارد: شروع، شرط ادامه، قدم بعدی.

کد · قابل اجراjs
for (let i = 1; i <= 5; i++) {
  console.log("شماره", i);
}
۲

while و do...while

وقتی تعداد دفعات از قبل معلوم نیست. do...while حداقل یک بار اجرا می‌شود.

کد · قابل اجراjs
let n = 3;
while (n > 0) { console.log(n); n--; }
let k = 10;
do { console.log("حداقل یک بار", k); k++; } while (k < 5);
۳

for...of و for...in

for...of روی مقدارهای آرایه می‌چرخد و for...in روی کلیدهای آبجکت.

کد · قابل اجراjs
for (const f of ["سیب", "موز"]) console.log(f);
const user = { name: "Ali", age: 30 };
for (const key in user) console.log(key, "=", user[key]);
۴

break و continue

کد · قابل اجراjs
for (let i = 1; i <= 10; i++) {
  if (i === 3) continue; // این دور را رد کن
  if (i === 6) break;    // کل حلقه را قطع کن
  console.log(i);
}
خطر

اگر شرط حلقه هیچ‌وقت false نشود، حلقه بی‌پایان می‌شود و صفحه قفل می‌کند. همیشه مطمئن شو متغیر شمارنده تغییر می‌کند.

★

تمرین‌ها

تمرین ۱

مجموع اعداد ۱ تا ۱۰۰

دیدن پاسخ
کد · قابل اجراjs
let sum = 0;
for (let i = 1; i <= 100; i++) sum += i;
console.log(sum); // 5050
تمرین ۲

فقط اعداد زوج بین ۱ تا ۲۰ را چاپ کن

دیدن پاسخ
کد · قابل اجراjs
for (let i = 2; i <= 20; i += 2) console.log(i);
تمرین ۳

چالش: جدول ضرب عدد ۷ را تا ۱۰ بنویس

دیدن پاسخ
کد · قابل اجراjs
for (let i = 1; i <= 10; i++) console.log(`7 × ${i} = ${7 * i}`);
روش تمرین

اول خودت حل کن، بعد پاسخ را ببین و با راه‌حل خودت مقایسه کن. چند راه درست برای یک مسئله وجود دارد.
