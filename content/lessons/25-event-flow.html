Bubbling و stopPropagation

وقتی روی یک المنت کلیک می‌کنی، رویداد از همان المنت به پدرانش «بالا می‌رود». این رفتار را Bubbling می‌نامند.

کد (HTML و JS) · قابل اجراhtml
<div id="outer" style="padding:20px;background:#e0f2fe">
  بیرونی
  <button id="inner">درونی</button>
</div>
<p id="log"></p>
<script>
const log = (t) => (document.getElementById("log").textContent += t + " ← ");
document.getElementById("outer").addEventListener("click", () => log("outer"));
document.getElementById("inner").addEventListener("click", () => log("inner"));
</script>

با e.stopPropagation() مسیر بالا رفتن را قطع می‌کنی. از آن کم استفاده کن، چون باعث می‌شود شنونده‌های دیگر پدرها نبینند چه شد.

Event Delegation

به جای وصل کردن شنونده به ۱۰۰ آیتم، یک شنونده به پدرشان وصل کن. مزیت بزرگ: آیتم‌هایی که بعداً ساخته می‌شوند هم خودکار کار می‌کنند.

کد (HTML و JS) · قابل اجراhtml
<ul id="menu">
  <li data-id="1">درس اول</li>
  <li data-id="2">درس دوم</li>
</ul>
<button id="add">آیتم جدید</button>
<p id="out"></p>
<script>
const menu = document.getElementById("menu");
menu.addEventListener("click", (e) => {
  const li = e.target.closest("li");
  if (!li) return;
  document.getElementById("out").textContent = "انتخاب شد: " + li.dataset.id;
});
let n = 2;
document.getElementById("add").onclick = () => {
  const li = document.createElement("li");
  li.dataset.id = ++n;
  li.textContent = "درس " + n;
  menu.append(li);        // بدون شنونده‌ی جدید کار می‌کند
};
</script>
۴

dataset و focus

ویژگی‌های data-* در HTML از طریق element.dataset خوانده می‌شوند. مثلاً data-user-id می‌شود dataset.userId. با input.focus() مکان‌نما را داخل فیلد می‌گذاری.

کد (HTML و JS) · قابل اجراhtml
<button id="b" data-user-id="42" data-role="admin">کاربر</button>
<input id="i" placeholder="اینجا فوکوس می‌شود">
<p id="out"></p>
<script>
const b = document.getElementById("b");
b.onclick = () => {
  document.getElementById("out").textContent = b.dataset.userId + " / " + b.dataset.role;
  document.getElementById("i").focus();
};
</script>
