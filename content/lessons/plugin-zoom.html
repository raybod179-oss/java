Medium Zoom: بزرگ‌نمایی تصویر

کلیک روی عکس، بزرگ‌نمایی نرم با پس‌زمینه‌ی تیره، مثل سایت Medium. این کتابخانه کوچک است (حدود ۹ کیلوبایت) و کل کارش را با یک خط انجام می‌دهد؛ جایگزین ساده‌ی لایت‌باکسی که برای گالری خودت نوشتی.

۱

نصب

در این صفحه برای اینکه نمونه‌ها بدون اینترنت و بدون وابستگی به CDN اجرا شوند، نسخه‌ی کتابخانه از خود سایت بارگیری می‌شود. در پروژه‌ی خودت یکی از این دو روش را به کار ببر:

روش ۱: CDN (فقط چند تگ در HTML)html
<script src="https://cdn.jsdelivr.net/npm/medium-zoom@1.1.2/dist/medium-zoom.min.js"></script>
روش ۲: npm (برای پروژه‌هایی که با Vite یا Webpack ساخته می‌شوند)txt
npm install medium-zoom
۲

استفاده‌ی پایه

یک انتخابگر CSS بده؛ همه‌ی تصاویر مطابق آن قابل بزرگ‌نمایی می‌شوند. این پیش‌نمایش تصویرها را با کد می‌سازد:

کد (HTML و JS) · قابل اجراhtml
<style> img { width: 130px; border-radius: 12px; margin: 6px; cursor: zoom-in; } </style>
<div id="pics"></div>

<script src="/assets/vendor/medium-zoom.min.js"></script>
<script>
const svg = (c) => "data:image/svg+xml;utf8," + encodeURIComponent(
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 320 200"><rect width="320" height="200" fill="' + c +
  '"/><circle cx="160" cy="100" r="50" fill="rgba(255,255,255,.4)"/></svg>');

["#f59e0b", "#22c55e", "#3b82f6"].forEach((c) => {
  const img = new Image();
  img.src = svg(c);
  img.alt = "نمونه";
  img.setAttribute("data-zoom", "");
  document.getElementById("pics").append(img);
});

mediumZoom("[data-zoom]", { background: "rgba(0,0,0,.85)", margin: 24 });
</script>
۳

گزینه‌ها و رویدادها

  • background: رنگ پس‌زمینه
  • margin: فاصله‌ی تصویر تا لبه‌ی صفحه
  • scrollOffset: چقدر اسکرول، بزرگ‌نمایی را ببندد
  • zoom.on("open") و on("closed"): رویدادها
رویدادهاjs
const zoom = mediumZoom("[data-zoom]");
zoom.on("open", () => console.log("باز شد"));
zoom.on("closed", () => console.log("بسته شد"));
zoom.close();      // بستن با کد
ترفند سرعت

برای تصویر بزرگ‌تر با کیفیت بالا، صفت data-zoom-src را روی img بگذار؛ تصویر کوچک در صفحه می‌ماند و فقط هنگام بزرگ‌نمایی نسخه‌ی بزرگ بارگیری می‌شود.
