۱

انواع اصلی

هر مقدار در جاوااسکریپت یک نوع دارد. با typeof نوع را می‌پرسی.

کد · قابل اجراjs
console.log(typeof "سلام");   // string
console.log(typeof 42);       // number
console.log(typeof true);     // boolean
console.log(typeof undefined);// undefined
console.log(typeof null);     // object (یک باگ قدیمی زبان)
console.log(typeof 10n);      // bigint

string متن است، number عدد صحیح و اعشاری، boolean فقط true یا false، undefined یعنی مقدار هنوز داده نشده و null یعنی عمداً خالی است.

۲

آرایه

لیست مرتب از مقدارها. شماره‌ی اندیس از صفر شروع می‌شود.

کد · قابل اجراjs
const fruits = ["سیب", "موز", "انار"];
console.log(fruits[0]);
console.log(fruits.length);
fruits.push("گیلاس");
console.log(fruits);
۳

آبجکت

مجموعه‌ای از جفت‌های کلید و مقدار، مناسب برای توصیف یک چیز واقعی مثل کاربر یا محصول.

کد · قابل اجراjs
const user = { name: "Sara", age: 24, isAdmin: false };
console.log(user.name);
user.city = "Shiraz";
console.log(user["city"]);
console.log(user);
اشتباه رایج

آرایه هم از نوع object است، پس typeof [] برابر object می‌شود. برای تشخیص آرایه از Array.isArray(x) استفاده کن.

تمرین ۱

کد · قابل اجراjs
