Async و Await

async/await همان Promise است با ظاهری که شبیه کد معمولی دارد. فقط داخل تابعی که با async تعریف شده می‌توان await نوشت و await اجرای همان تابع را تا آماده شدن نتیجه متوقف می‌کند (بقیه‌ی برنامه متوقف نمی‌شود).

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. الگوی پایه با try/catch
  2. پشت‌سرهم یا هم‌زمان؟
  3. Async داخل حلقه
  4. تمرین‌ها
۱

الگوی پایه با try/catch

کد · قابل اجراjs
const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
async function getUser(id) {
  await wait(200);
  if (id <= 0) throw new Error("شناسه نامعتبر");
  return { id, name: "Sara" };
}

async function main() {
  try {
    const u = await getUser(1);
    console.log("کاربر:", u.name);
    await getUser(-1);                 // اینجا خطا می‌دهد
    console.log("این خط اجرا نمی‌شود");
  } catch (e) {
    console.log("خطا:", e.message);
  } finally {
    console.log("پایان");
  }
}
main();
نکته

تابع async همیشه یک Promise برمی‌گرداند، پس برای نتیجه‌اش هم می‌توانی await یا .then بنویسی.

۲

پشت‌سرهم یا هم‌زمان؟

اگر کارها به هم وابسته نیستند، آن‌ها را با Promise.all هم‌زمان اجرا کن. زمان کل از مجموع به بزرگ‌ترین زمان کاهش می‌یابد.

کد · قابل اجراjs
const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
async function demo() {
  let t = Date.now();
  await wait(300);
  await wait(300);
  console.log("پشت‌سرهم، حدود ۶۰۰ میلی‌ثانیه:", Date.now() - t >= 550);

  t = Date.now();
  await Promise.all([wait(300), wait(300)]);
  console.log("هم‌زمان، حدود ۳۰۰ میلی‌ثانیه:", Date.now() - t < 500);
}
demo();
۳

Async داخل حلقه

کد · قابل اجراjs
const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
async function demo() {
  for (const id of [1, 2, 3]) {
    await wait(100);
    console.log("پردازش شد:", id);   // به ترتیب
  }
  console.log("حلقه تمام شد");
}
demo();
دام معروف

forEach منتظر await نمی‌ماند. اگر داخلش تابع async بدهی، حلقه تمام می‌شود و کارها هنوز در جریان‌اند. برای ترتیب از for...of و برای هم‌زمانی از Promise.all(arr.map(...)) استفاده کن.

کد · قابل اجراjs
const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
async function bad() {
  [1, 2].forEach(async (n) => {
    await wait(100);
    console.log("داخل forEach:", n);
  });
  console.log("بعد از forEach (زودتر از همه)");
}
bad();

تمرین‌ها

تمرین ۱

تابع async بنویس که ۲ عدد را بعد از ۲۰۰ میلی‌ثانیه جمع کند و با await چاپ کنی

دیدن پاسخ
کد · قابل اجراjs
const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
const add = async (a, b) => { await wait(200); return a + b; };
(async () => console.log(await add(2, 3)))();
تمرین ۲

چالش: سه کار را هم‌زمان اجرا کن و نتیجه‌ها را یک‌جا چاپ کن

دیدن پاسخ
کد · قابل اجراjs
const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
const job = async (n) => { await wait(100 * n); return "کار " + n; };
(async () => {
  const results = await Promise.all([job(1), job(2), job(3)]);
  console.log(results);
})();
