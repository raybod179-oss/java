ارث‌بری (Inheritance)

وقتی چند کلاس ویژگی‌های مشترک دارند، یک کلاس پدر می‌سازی و بقیه از آن extends می‌کنند، تا کد تکراری ننویسی.

توی این درس چه چیزهایی یاد می‌گیریم؟

  1. مقدمه
  2. super
  3. تمرین‌ها
۱

مقدمه

کد · قابل اجراjs
class Animal {
  constructor(name) { this.name = name; }
  eat() { return `${this.name} غذا می‌خورد`; }
  speak() { return `${this.name} صدا می‌دهد`; }
}
class Dog extends Animal {
  constructor(name, breed) {
    super(name);            // اول سازنده‌ی پدر را صدا بزن
    this.breed = breed;
  }
  speak() {                 // بازنویسی (Override)
    return `${this.name}: هاپ هاپ`;
  }
}
const d = new Dog("Rex", "Husky");
console.log(d.eat());
console.log(d.speak());
console.log(d instanceof Dog, d instanceof Animal);
۲

super

در constructor کلاس فرزند، قبل از استفاده از this حتماً super() را بزن. داخل متد هم با super.متد() می‌توانی نسخه‌ی پدر را صدا بزنی و چیزی به آن اضافه کنی.

کد · قابل اجراjs
class Base {
  info() { return "پایه"; }
}
class Child extends Base {
  info() { return super.info() + " + اضافه"; }
}
console.log(new Child().info());
اشتباه رایج

اگر در کلاس فرزند constructor بنویسی و super را صدا نزنی، با خطای ReferenceError روبه‌رو می‌شوی.

قانون طلایی

ارث‌بری برای رابطه‌ی «است» خوب است (سگ یک حیوان است). برای رابطه‌ی «دارد» (ماشین موتور دارد) از ترکیب آبجکت‌ها استفاده کن.

تمرین ۱

کلاس Admin که از User ارث ببرد و فیلد role داشته باشد

دیدن پاسخ
کد · قابل اجراjs
class User { constructor(name) { this.name = name; } }
class Admin extends User {
  constructor(name) { super(name); this.role = "admin"; }
}
console.log(new Admin("Ali"));
تمرین ۲

چالش: سه شکل Shape، Circle و Square با متد area

دیدن پاسخ
کد · قابل اجراjs
class Shape { area() { return 0; } }
class Circle extends Shape {
  constructor(r) { super(); this.r = r; }
  area() { return Math.round(Math.PI * this.r ** 2); }
}
class Square extends Shape {
  constructor(s) { super(); this.s = s; }
  area() { return this.s ** 2; }
}
console.log(new Circle(3).area(), new Square(4).area());
