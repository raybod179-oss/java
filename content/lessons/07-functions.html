توابع و Arrow Function

هر بخش کوتاه است، کد دارد، خروجی را نشانت می‌دهد و آخرش تمرین. کدها را خودت تایپ کن؛ کپی کردن یاد نمی‌دهد.

۱

تابع چیست؟

بلوکی از کد که اسم دارد و هر وقت صدایش کنی اجرا می‌شود. با ورودی (پارامتر) کار می‌کند و با return نتیجه می‌دهد.

کد · قابل اجراjs
function add(a, b) {
  return a + b;
}
console.log(add(2, 3));

function greet(name = "مهمان") {   // مقدار پیش‌فرض
  return `سلام ${name}`;
}
console.log(greet(), greet("Rayvo"));
نکته

هر کدی بعد از return اجرا نمی‌شود. تابعی که return ندارد مقدار undefined برمی‌گرداند.

۲

Function Expression و Arrow

کد · قابل اجراjs
const mul = function (a, b) { return a * b; };
const sq = (n) => n * n;          // Arrow Function
const hi = () => "سلام";
console.log(mul(3, 4), sq(5), hi());
۳

Rest Operator

گرفتن تعداد نامحدود ورودی داخل یک آرایه.

کد · قابل اجراjs
const sum = (...nums) => nums.reduce((a, b) => a + b, 0);
console.log(sum(1, 2, 3, 4));
۴

IIFE

تابعی که همان لحظه‌ی تعریف اجرا می‌شود و متغیرهایش بیرون دیده نمی‌شوند.

کد · قابل اجراjs
(function () {
  const secret = "فقط اینجا";
  console.log(secret);
})();

تمرین‌ها

تمرین ۱

تابعی بنویس که عدد بگیرد و بگوید زوج است یا فرد

دیدن پاسخ
کد · قابل اجراjs
const parity = (n) => (n % 2 === 0 ? "زوج" : "فرد");
console.log(parity(7));
تمرین ۲

تابعی که میانگین هر تعداد عدد را حساب کند

دیدن پاسخ
کد · قابل اجراjs
const avg = (...n) => n.reduce((a, b) => a + b, 0) / n.length;
console.log(avg(10, 20, 30));
