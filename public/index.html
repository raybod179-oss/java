درباره‌ی دوره

جاوااسکریپت را یاد می‌گیری و با آن چیز می‌سازی، نه فقط می‌خوانی

جاوااسکریپت زبان اصلی وب است و قدم دوم مسیر فول‌استک بعد از HTML و CSS. این دوره مفهوم را ساده توضیح می‌دهد، بلافاصله کدش را جلوی چشمت اجرا می‌کند و با تمرین و پروژه محکمش می‌کند.

تو چه کسی می‌شوی

کسی که جاوااسکریپت مدرن (ES6 به بعد) را درست می‌فهمد: متغیر و تابع و Scope، آرایه و آبجکت، کلاس و ارث‌بری، DOM و رویدادها، Promise و async/await و کار با API.

۲۲ پروژه‌ی عملی

هفت پروژه‌ی مبتدی، هفت پروژه‌ی متوسط و هشت پروژه‌ی پیشرفته: از شمارنده و مودال تا موزیک پلیر، فروشگاه، Movie API و برنامه‌ی آب‌وهوا. سورس هر پروژه قابل دانلود است.

از صفر واقعی

مسیر از متغیر و شرط شروع می‌شود و تا ناهمزمانی و Fetch ادامه دارد. در هر درس اشتباه‌های رایج مبتدی‌ها و راه جلوگیری از آن‌ها نوشته شده است.

مناسب چه کسی است

کسی که HTML و CSS را در حد مقدماتی می‌شناسد و می‌خواهد صفحه‌ها را زنده کند. اگر هنوز HTML بلد نیستی، اول دوره‌ی رایگان HTML و CSS رایو را ببین.

مسیر پیشنهادی فول‌استک: ۱) دوره‌ی رایگان HTML و CSS ← ۲) همین دوره‌ی جاوااسکریپت ← ۳) دوره‌ی لاراول (بک‌اند). با این سه قدم از صفر به یک برنامه‌نویس وب کامل می‌رسی.

شفاف بگویم: دوره متنی است و ویدیو ندارد؛ برای همین قیمتش از دوره‌های ویدیویی ۴۰ تا ۷۰ ساعته پایین‌تر است. همه‌ی درس‌ها و ۲۲ پروژه‌ی دوره آماده است؛ درس‌ها و پروژه‌های جدید هم بعداً برای خریداران رایگان اضافه می‌شود. سه درس کامل را قبل از خرید رایگان بخوان.

    سؤالات متداول

    قبل از خرید بدان

    برای کسی که می‌خواهد جاوااسکریپت را درست و از پایه یاد بگیرد: چه کاملاً مبتدی باشی، چه کمی HTML و CSS بلد باشی. فقط آشنایی ابتدایی با HTML لازم است؛ اگر آن را بلد نیستی، دوره‌ی رایگان HTML و CSS رایو را اول ببین.

    می‌توانی صفحه‌های تعاملی بسازی، با API کار کنی، ابزارها و برنامه‌های کوچک وب بنویسی و بعد مسیر را ادامه بدهی: لاراول برای بک‌اند یا یک فریم‌ورک مثل React. دوره‌ی ۲۲ پروژه‌ای تو را از «بلدم» به «ساخته‌ام» می‌رساند.

    بعد از پرداخت، یک کد دسترسی اختصاصی برایت ارسال می‌شود. با آن از همین سایت (بخش «ورود دانشجویان») وارد می‌شوی و پیشرفتت ذخیره می‌شود.

    نه. دوره متنی و تعاملی است: توضیح کوتاه، کد قابل اجرا همان‌جا در صفحه، تمرین با پاسخ و پروژه‌های قابل دانلود. سرعت یادگیری دست خودت است و هر بخش را دوباره می‌خوانی.

    همه‌ی ۲۲ پروژه‌ی دوره منتشر شده است. درس‌ها و پروژه‌های جدیدی که بعداً اضافه شود هم برای همه‌ی خریداران رایگان باز می‌شود. هر پروژه که اضافه شود، خودکار برای همه‌ی خریداران باز می‌شود و هزینه‌ی جدید ندارد.

    ۳ ماه پشتیبانی مستقیم خود مدرس (رایبد اکبرلو) در تلگرام، از اولین ورود تو به دوره. هر پنج‌شنبه تا ۱۰ سؤال و هر جمعه تا ۱۰ سؤال، یعنی ۲۰ سؤال در هفته. بعد از ۳ ماه پشتیبانی تمام می‌شود؛ دسترسی به درس‌ها باقی می‌ماند.

    نه. چون محتوا دیجیتال است و بعد از دریافت کد کامل در دسترس قرار می‌گیرد، مبلغ پرداخت‌شده بازگردانده نمی‌شود (مگر اضافه‌پرداخت). برای همین سه درس کامل رایگان است تا قبل از خرید خودت قضاوت کنی.

    هر کد مخصوص یک نفر و یک‌بار مصرف است و با اولین ورود به همان مرورگر قفل می‌شود؛ در مرورگر یا دستگاه دوم پیام «استفاده‌شده» می‌بینی. برای راحتی، دوره را همیشه با یک مرورگر ثابت باز کن.

    اگر کوکی‌های مرورگر را پاک کنی، حالت ناشناس بزنی یا مرورگر/دستگاه را عوض کنی، قفل از دست می‌رود. در این حالت به پشتیبانی در تلگرام پیام بده و همان شماره یا آیدی تلگرامی که با آن دوره را خریده‌ای را بفرست؛ کد قبلی غیرفعال و یک کد تازه ساخته می‌شود.

    نه. روی صفحات دوره نام و شناسه‌ی خریدار نمایش داده می‌شود. کپی و بازنشر دوره ممنوع است و در صورت سوءاستفاده کد غیرفعال می‌شود.
