# دوره‌ی جاوااسکریپت Rayvo | نسخه‌ی Netlify

همان سیستم دوره‌ی لاراول (کد دسترسی یک‌مرورگره، پنل مدیر، پشتیبانی ۳ ماهه، نظرات، مدرس و تیزر) برای دوره‌ی جاوااسکریپت.

## ساختار
- `public/` : صفحه‌ی فروش، ورود، ظاهر سایت و پنل مدیر (`public/rv-admin-ziftk6h4e5zmb1p7o4grv1qb9nen8r/`)
- `content/lessons/` : درس‌ها (بیرون از پوشه‌ی منتشرشده؛ فقط با جلسه‌ی معتبر ارسال می‌شود، به‌جز درس‌های رایگان)
- `content/downloads/` : zip پروژه‌ها (نام انگلیسی مثل `project-counter.zip`؛ فقط برای دانشجوی واردشده)
- `netlify/functions/` و `netlify/lib/` : ورود، دروازه‌ی محتوا، API پنل، امنیت
- `tools/e2e-test.mjs` : تست خودکار کل سیستم، `local-test.mjs` : اجرای محلی

## راه‌اندازی (بدون هیچ متغیر محیطی)
1. ریپوی **Private** در GitHub بساز و محتوای همین پوشه را (بدون node_modules) آپلود کن.
2. در Netlify: Import from Git ← همان ریپو ← Deploy. نام سایت را `rayvo-javascript` بگذار تا با آدرس‌های داخل سایت (canonical، sitemap، og:image) یکی باشد.
3. آدرس پنل مدیر: `https://rayvo-javascript.netlify.app/rv-admin-ziftk6h4e5zmb1p7o4grv1qb9nen8r/` (این آدرس را جایی منتشر نکن).
4. ورود با «شماره‌ی مدیر» و «رمز مدیر» (در کد فقط هش scrypt هست، نه خود رمز). بعد از اولین ورود از «تنظیمات» رمز را عوض کن.
5. در پنل ← «وضعیت سیستم» را بزن؛ همه‌چیز باید سبز باشد.

## قیمت‌ها (از پنل «مدرس، تیزر و قیمت» قابل تغییر است)
- قیمت اصلی: ۱٬۰۰۰٬۰۰۰ تومان
- ۱۰ نفر اول: ۳۵٪ تخفیف = ۶۵۰٬۰۰۰ تومان
- نفر ۱۱ تا ۱۵: ۲۵٪ تخفیف = ۷۵۰٬۰۰۰ تومان
- از نفر ۱۶: قیمت اصلی
مرحله‌ها خودکار با تعداد کدهای ساخته‌شده جلو می‌روند؛ برای فروش خارج از سایت از «تصحیح تعداد فروش» استفاده کن.

## درس‌های رایگان
فهرست، معرفی جاوااسکریپت، متغیرها و انواع داده. برای تغییر، آرایه‌ی `FREE` را هم در `netlify/lib/auth.mjs` و هم در `public/assets/js/rayvo.js` یکسان ویرایش کن.

## افزودن درس یا پروژه
1. فایل HTML درس را در `content/lessons/` بگذار (نام انگلیسی، با همان قالب درس‌های موجود).
2. در `public/assets/js/rayvo.js` در آرایه‌ی `LEVELS` نام فایل را به‌جای مورد «به‌زودی» بگذار (مثلاً `["project-counter.html","پروژه‌ی شمارنده‌ی عدد",45]`).
3. zip سورس پروژه را در `content/downloads/` بگذار.
4. Deploy (Git push).

## کتابخانه‌های داخلی
نمونه‌های زنده‌ی درس‌های پلاگین از کتابخانه‌های داخل `public/assets/vendor/` (با مجوز MIT و Apache-2.0 در `LICENSES.txt`) لود می‌شوند، نه از CDN؛ پس بدون اینترنت خارجی هم کار می‌کنند. نسخه‌ی Typed.js عمداً ۲٫۱٫۰ (MIT) است؛ نسخه‌ی ۳ مجوز GPL دارد.

## میزبان‌های مجاز در CSP
نمونه‌های اجرای زنده از این APIهای رایگان استفاده می‌کنند: `jsonplaceholder.typicode.com`، `api.tvmaze.com`، `picsum.photos`، `open-meteo.com`. اگر API دیگری اضافه کردی، آدرسش را در `netlify.toml` و `netlify/lib/headers.mjs` به `connect-src` (و برای تصویر `img-src`) اضافه کن.

## امنیت
- کدهای دسترسی فقط به‌صورت هش و رمزنگاری‌شده نگهداری می‌شوند و هیچ فهرستی از آن‌ها به مرورگر کاربران نمی‌رسد.
- هر کد با اولین ورود به یک مرورگر قفل می‌شود؛ مرورگر دوم رد می‌شود. غیرفعال/ریست/حذف فوراً اثر می‌کند.
- مدیر: حداکثر ۳ ورود هم‌زمان؛ بعد از ۵ تلاش اشتباه ۳۰ دقیقه قفل؛ بررسی Origin؛ هدرهای CSP و HSTS.
- درس‌های پولی و zipها هرگز مستقیم سرو نمی‌شوند.

## محدودیت‌ها (صادقانه)
- «یک‌بار مصرف» یعنی قفل به یک مرورگر؛ با پاک شدن کوکی یا عوض شدن گوشی به ریست نیاز است.
- اسکرین‌شات یا کپی دستی را هیچ سیستمی صددرصد نمی‌بندد؛ واترمارک نام خریدار و باطل کردن کد بازدارنده‌ی اصلی است.
- کد درس‌ها با Node و مثال‌های DOM با jsdom آزموده شده‌اند، اما سایت روی Netlify واقعی و مرورگر واقعی را باید خودت یک بار امتحان کنی.
- پلن رایگان Netlify سقف دارد؛ قبل از فروش زیاد، شرایط فعلی را ببین.
